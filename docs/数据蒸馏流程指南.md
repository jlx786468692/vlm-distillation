## 1. 项目概览

### 1.1 项目核心特性

本项目是一个完整的 VLM数据蒸馏清洗管道，专注于VQA任务：

| 特性 | 说明 | 实现状态 |
|------|------|----------|
| **三重标签生成** | 硬标签 + 软标签 + 思维链 | ✅ 100% |
| **VQA任务支持** | 视觉问答任务 | ✅ 100% |
| **数据质量校验** | KL散度、ECE、幻觉检测、Top-K匹配 | ✅ 100% |
| **数据清洗** | 异常检测 + 质量评分 + 过滤修复 | ✅ 100% |
| **可视化** | 4个核心图表 | ✅ 100% |
| **一键运行** | 整合蒸馏+校验+清洗+验证+可视化流程 | ✅ 100% |

### 1.2 技术栈

| 组件 | 技术 |
|------|------|
| Teacher模型 | Qwen2.5-VL-32B-AWQ |
| 数据集 | COCO val2014 |
| 推理框架 | transformers + autoawq |
| 温度缩放 | T=4 |
| Token过滤 | 四层防护策略 |

## 2. 整体流程设计

### 2.1 六步骤流程概览

| 步骤 | 名称 | 输入 | 处理 | 输出 | 文档链接 |
|------|------|------|------|------|----------|
| **Step 1** | 数据蒸馏 | COCO数据集 | TeacherModel推理生成三重标签 | merged/*.json | [标签生成指南](三种标签生成和训练指南.md) |
| **Step 2** | 初始验证 | merged/*.json | 数据完整性、格式检查 | validation_initial.json | - |
| **Step 3** | 数据清洗 | merged/*.json | 异常检测+质量评分+清洗 | cleaned/*.json | [清洗系统报告](数据清洗系统详细报告.md) |
| **Step 4** | 最终验证 | cleaned/*.json | 确认清洗效果 | validation_final.json | - |
| **Step 5** | 质量校验 | cleaned/*.json | 深度质量评估，训练前把关 | quality_validation_report.json | [质量校验详解](数据质量校验系统详解.md) |
| **Step 6** | 可视化 | 所有数据 | 生成对比图表 | PNG图像 | - |

### 2.2 流程设计说明

1. **初始验证**: 快速检查数据完整性和格式正确性
2. **数据清洗**: 根据初始验证发现的问题进行清洗
3. **最终验证**: 验证清洗效果，确认数据改善
4. **质量校验**: 深度质量评估（KL散度、ECE、幻觉检测），判断是否具备训练价值

> ⚠️ **重要**: 质量校验放在清洗后作为最终把关，而不是蒸馏后立即执行。这样可以确保在训练前对清洗后的数据进行深度质量评估。

## 4. 三重标签生成

### 4.1 两阶段推理设计

```
阶段1: Hard Label + Soft Label (标准Prompt, 低显存)
    ├─ 输入: image + question
    ├─ 输出: answer + confidence + logits
    └─ 用途: 获取答案和概率分布

阶段2: CoT生成 (CoT Prompt, 复用视觉特征)
    ├─ 输入: image + question + primary_answer + allowed_answers
    ├─ 输出: Observation / Analysis / Conclusion
    └─ 用途: 获取推理过程
```

### 4.2 硬标签 (Hard Label)

**生成逻辑**：
```python
# 阶段1: 获取答案和置信度
result = teacher.inference_vqa(
    image=image_path,
    question=question,
    return_logits=True,
    generate_cot=False
)

# 输出格式
{
    "answer": "kitchen",
    "confidence": 0.92,
    "logits": {...}  # 供软标签使用
}
```

**置信度过滤**：
- 阈值：0.4
- 低于阈值：跳过CoT生成，标记为filtered

详细文档：[三种标签生成和训练指南](三种标签生成和训练指南.md)

### 4.3 软标签 (Soft Label)

**温度缩放原理**：
```
原始分布: P(y) = softmax(logits)
温度分布: P_T(y) = softmax(logits / T)

T=1:  [0.95, 0.03, 0.02]  ← 过于尖锐
T=4:  [0.85, 0.10, 0.05]  ← 平滑合理 ✅ (当前使用)
T=5:  [0.60, 0.25, 0.15]  ← 过于平滑
```

**Token过滤四层策略**：
1. **黑名单过滤**：拦截BPE碎片、噪音词
2. **硬标签保护**：确保正确答案不丢失
3. **Top-K兜底**：保证多样性（最少10个token）
4. **任务适配**：白名单过滤（count/color/binary）

详细文档：[Token过滤完整指南](Token过滤完整指南.md)

### 4.4 思维链 (CoT)

**生成逻辑**：
```python
# 阶段2: 使用soft_label的约束生成CoT
cot = teacher.inference_vqa(
    image=image_path,
    question=question,
    generate_cot=True,
    primary_answer=soft_label['primary_answer'],
    allowed_answers=soft_label['allowed_answers']
)

# 输出格式
{
    "structured_reasoning": {
        "observation": "I observe...",
        "analysis": "I analyze...",
        "conclusion": "Final Answer: kitchen"
    },
    "quality_metrics": {
        "is_valid": true
    }
}
```

详细文档：[三种标签生成和训练指南](三种标签生成和训练指南.md)

## 6. 配置参数

### 6.1 教师模型配置

```yaml
teacher:
  model_name: "models/Qwen2.5-VL-32B-Instruct-AWQ"
  device: "cuda"
  precision: "4bit"           # AWQ 4-bit量化
  temperature: 0.0            # 贪婪解码
  max_new_tokens: 768         # 最大生成token数
  cache_visual_features: true # 视觉特征缓存
```

### 6.2 蒸馏配置

```yaml
distillation:
  tasks: ["vqa"]
  
  hard_labels:
    enabled: true
    confidence_threshold: 0.4    # 置信度阈值
  
  soft_labels:
    enabled: true
    temperature: 4               # 温度参数
    top_k_logits: 50             # Top-K logits
  
  cot:
    enabled: true
    max_length: 512              # 最大长度
    structured_output: true      # 结构化输出
```

### 6.3 数据清洗配置

```yaml
cleaning:
  min_confidence: 0.3           # 最低置信度
  max_confidence: 0.95           # 最高置信度
  min_quality_score: 35.0        # 最低质量分数
  min_cot_quality: 0.3           # 最低CoT质量
  
  auto_remove_invalid: true      # 自动移除无效数据
  remove_empty_results: false    # 移除空结果
  deduplicate_answers: true      # 答案去重
  
  invalid_answers:               # 无效答案列表
    - "unknown"
    - "n/a"
    - "none"
```

### 6.4 Token过滤配置

详细配置见：`configs/vqa_token_filter.yaml`

```yaml
# 任务白名单
task_whitelists:
  count: ["zero", "one", "two", ...]
  color: ["red", "green", "blue", ...]
  binary: ["yes", "no"]

# 黑名单
blacklists:
  special_tokens: ["<pad>", "</s>", ...]
  noise_words: ["the", "a", "an", ...]
```

详细文档：[Token过滤完整指南](Token过滤完整指南.md)
