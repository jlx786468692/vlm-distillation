## 1. 三种标签概述

### 为什么需要三种标签？

在知识蒸馏中，教师模型（大模型）的知识通过三种形式传递给学生模型（小模型）：

| 标签类型 | 知识类型 | 训练作用 |
|---------|---------|---------|
| **硬标签** | 确定性知识 | 学习"正确答案" |
| **软标签** | 不确定性知识（暗知识） | 学习"答案间的关系" |
| **思维链** | 推理过程 | 学习"如何思考" |

### 比喻理解

想象学生考试：

- **硬标签**：标准答案（答案是对的）
- **软标签**：老师的评分分布（答案A给85分，答案B给15分，说明答案A比B好多少）
- **思维链**：解题步骤（先观察，再分析，最后得出结论）

## 2. 推理策略对比

### 2.1 为什么需要不同的推理策略？

三种标签（硬标签、软标签、CoT）可以通过不同次数的模型推理生成：

- **一次推理**：一次推理生成所有标签
- **两次推理**：一次生成硬标签+软标签，另一次生成CoT
- **三次推理**：每种标签分别推理生成

不同的推理策略在**效率、质量、一致性**上有不同的权衡。

### 2.2 本项目的推理策略：两次推理 + 视觉特征缓存 ⭐

```
┌─────────────────────────────────────────────────────────────┐
│                      第一次推理                               │
│  输入: 图像 + 问题                                           │
│  输出: 硬标签 + Logits (用于生成软标签)                      │
│  参数: temperature=0 (贪婪解码)                              │
│  特点: 确定性输出，同时缓存视觉特征                           │
│  缓存: 缓存图像视觉Embedding（节省第二次编码）                │
└─────────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────────┐
│                      第二次推理                               │
│  输入: 缓存的视觉特征 + 问题 + 主答案 + 允许答案列表           │
│  输出: 思维链 (CoT)                                          │
│  参数: temperature=0.1 (低温度采样)                          │
│  特点: 跳过图像编码，直接使用缓存的视觉特征                    │
│  优化: 节省约150ms的图像编码时间                              │
└─────────────────────────────────────────────────────────────┘
```

#### 性能优化：视觉特征缓存

**优化原理**：第二次推理复用第一次的视觉特征，避免重复编码

**时间对比**：

| 阶段 | 第一次推理 | 第二次推理（无缓存） | 第二次推理（有缓存） | 节省时间 |
|------|-----------|-------------------|-------------------|---------|
| 图像加载 | 5ms | 5ms | 0ms | 5ms |
| 图像预处理 | 10ms | 10ms | 0ms | 10ms |
| **视觉编码器** | **150ms** | **150ms** | **0ms** | **150ms** ⭐ |
| 文本编码 | 5ms | 5ms | 5ms | 0ms |
| 多模态融合 | 20ms | 20ms | 20ms | 0ms |
| 文本生成 | 100ms | 300ms | 300ms | 0ms |
| **总计** | **290ms** | **490ms** | **340ms** | **150ms** |

**总体性能提升**：
- 原始两次推理：290ms + 490ms = 780ms
- 优化后两次推理：290ms + 340ms = **630ms**
- **性能提升：19%** ⭐

#### 第一次推理：生成硬标签和软标签

**代码位置**: `src/distillation/vqa_soft_label_gen.py:102-130`

```python
def generate_vqa_soft_labels(self, image_path, question, hard_label_result):
    """
    生成VQA软标签（使用硬标签的Logits）
    
    关键：一次推理同时获取硬标签和Logits
    """
    # 🔧 从 hard_label 获取 logits（第一次推理的结果）
    if hard_label_result and 'logits' in hard_label_result:
        logits_data = hard_label_result['logits']
        primary_answer = hard_label_result.get('answer', '')
        
        # 🔧 使用Logits生成软标签（无需额外推理）
        distribution = self._process_vqa_logits(
            logits_data=logits_data,
            question=question,
            primary_answer=primary_answer
        )
        
        return {
            'answer_distribution': distribution,
            'primary_answer': primary_answer
        }
```

**为什么硬标签和软标签可以一次推理生成？**

1. **硬标签**：模型输出的答案（如"green"）
2. **软标签**：模型输出的Logits（答案的概率分布）
3. **关键**：两者来自同一次推理，只是提取的不同部分

```
模型输出结构:
├── sequences: [green, blue, gray, ...]  → 提取第一个 → 硬标签: "green"
└── logits: [8.5, 7.2, 5.8, ...]          → 温度缩放   → 软标签: {"green": 0.45, "blue": 0.35}
```

#### 第二次推理：生成思维链（使用缓存的视觉特征）

**代码位置**: `src/models/teacher_model.py:420-520`

```python
def inference_vqa_with_cot(self, image, question, primary_answer, allowed_answers):
    """
    生成思维链（第二次推理）
    
    为什么需要第二次推理？
    1. CoT需要更长的生成长度（512 tokens vs 50 tokens）
    2. CoT需要不同的温度参数（0.1 vs 0）
    3. CoT需要限定答案范围（从allowed_answers中选择）
    
    🔧 优化：使用缓存的视觉特征，跳过图像编码
    """
    # 构建CoT Prompt（包含答案范围限定）
    cot_prompt = self._construct_cot_prompt(
        question=question,
        primary_answer=primary_answer,
        allowed_answers=allowed_answers  # 从软标签提取
    )
    
    # 🔧 使用缓存的视觉特征（节省150ms）
    inputs = self._prepare_inputs(
        image, cot_prompt,
        use_cached_visual=True,   # 使用缓存的视觉特征
        image_id=image_id          # 相同的图像ID
    )
    
    # 使用低温度采样（temperature=0.1）
    outputs = self._generate(
        inputs,
        temperature=0.1,
        max_new_tokens=512
    )
    
    return {
        'cot_reasoning': self._parse_cot_output(outputs)
    }
```

### 2.3 四种推理策略详细对比

#### 策略1：一次推理生成所有标签

```
┌─────────────────────────────────────────────────────────────┐
│                    单次推理策略                               │
│  输入: 图像 + 问题                                           │
│  输出: 答案 + Logits + 推理过程                              │
│  Prompt: "What color is the water? Think step by step and   │
│          answer. Answer: ..."                               │
└─────────────────────────────────────────────────────────────┘
```

**优点**：
- ✅ **效率最高**：只需一次模型调用
- ✅ **成本最低**：节省50%推理时间和成本
- ✅ **一致性好**：硬标签、软标签、CoT来自同一推理

**缺点**：
- ❌ **质量降低**：CoT和答案生成互相干扰
- ❌ **参数冲突**：CoT需要temperature=0.1，硬标签需要temperature=0
- ❌ **长度限制**：CoT需要512 tokens，影响logits质量
- ❌ **答案范围未限定**：CoT可能输出不在软标签范围内的答案

**性能数据**：
- 推理次数：1次
- 总耗时：约290ms
- 适用场景：快速原型开发、计算资源受限

```python
    执行VQA推理，生成硬标签
    
    Args:
        image: 图像路径
        question: 问题文本
        return_logits: 是否返回logits（用于软标签生成）
    
    Returns:
        {
            'answer': 'green',           # 硬标签答案
            'confidence': 0.92,          # 置信度
            'logits': {                  # Logits数据（用于软标签）
                'top_k_indices': tensor([...]),
                'top_k_values': tensor([...])
            }
        }
    """
    # Step 1: 构建Prompt
    prompt = self._construct_prompt(question, task="vqa")
    # 结果: "<image>\nWhat is the color of the water?\nAnswer:"
    
    # Step 2: 准备输入
    inputs = self._prepare_inputs(image, prompt)
    # 结果: {
    #     'input_ids': tensor([[1, 2, 3, ...]]),
    #     'pixel_values': tensor([...]),
    #     'image_grid_thw': tensor([...])
    # }
    
    # Step 3: 模型推理
    # temperature=0: 贪婪解码，确保结果确定性
    outputs = self._generate(inputs, return_logits=return_logits)
    # 结果: GeneratedOutput(
    #     sequences=tensor([[1, 2, 3, ..., 100, 101, ...]]),
    #     logits=tensor([...])
    # )
    
    # Step 4: 提取答案
    generated_tokens = outputs.sequences[0]
    answer_tokens = generated_tokens[len(inputs['input_ids'][0]):]
    answer = self.tokenizer.decode(answer_tokens, skip_special_tokens=True)
    # 结果: "green"
    
    # Step 5: 计算置信度
    if return_logits:
        # 提取第一个token的logits
        first_token_logits = outputs.logits[0, len(inputs['input_ids'][0]), :]
        
        # 计算概率
        probs = torch.softmax(first_token_logits, dim=-1)
        
        # 获取最高概率
        top_prob, top_idx = torch.max(probs, dim=0)
        confidence = top_prob.item()
        # 结果: 0.92
        
        # 提取Top-K logits（用于软标签生成）
        top_k = 50  # 从配置读取
        top_k_values, top_k_indices = torch.topk(first_token_logits, top_k)
        
        return {
            'answer': answer.strip(),
            'confidence': confidence,
            'logits': {
                'top_k_indices': top_k_indices,
                'top_k_values': top_k_values
            }
        }
    
    return {
        'answer': answer.strip(),
        'confidence': None
    }
```

## 4. 软标签生成详解

### 3.1 定义

**软标签**是教师模型输出的**概率分布**，反映对各个答案的"不确定程度"，包含"暗知识"（Dark Knowledge）。

### 3.2 生成流程

```
┌─────────────────────────────────────────────────────────┐
│ Step 1: 获取硬标签和Logits                               │
│   - 调用 inference_vqa(return_logits=True)              │
│   - 结果: {'answer': 'green', 'logits': {...}}          │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│ Step 2: 提取第一个Token的Logits                          │
│   - 原因: VQA答案通常是单个token                          │
│   - 输入: top_k_indices, top_k_values                   │
│   - 输出: first_token_indices, first_token_logits       │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│ Step 3: 温度缩放                                         │
│   - 公式: scaled_logits = logits / temperature          │
│   - 参数: temperature = 4（配置）                        │
│   - 作用: 平滑概率分布，保留暗知识                        │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│ Step 4: 三层防护过滤                                     │
│   第一层：黑名单过滤（拦截噪音Token）                     │
│   第二层：硬标签保护（确保正确答案不丢失）                │
│   第三层：Top-K兜底（防止过度过滤）                       │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│ Step 5: 解码Token并构建分布                              │
│   - 解码token ID到单词                                   │
│   - 过滤低概率token (< 0.001)                            │
│   - 验证token完整性                                      │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│ Step 6: 等价Token合并                                    │
│   - 示例: '1' + 'one' = 'one'                           │
│   - 示例: 'gray' + 'grey' = 'gray'                      │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│ Step 7: 多Token答案标准化                                │
│   - 问题: "hotdog"被分词成["hot", "dog"]                │
│   - 解决: 将第一个token的概率映射到完整答案               │
│   - 示例: "hot": 0.143 -> "hotdog": 0.143              │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│ Step 8: 归一化和最终输出                                 │
│   - 确保概率和为 1.0                                     │
│   - 格式化输出: JSON格式                                 │
└─────────────────────────────────────────────────────────┘
                          ↓
                     软标签结果
```

### 3.3 代码实现

**位置**: `src/distillation/vqa_soft_label_gen.py:199-564`

```python
def _process_vqa_logits(self, logits_data, question, primary_answer):
    """
    处理VQA logits，生成软标签
    
    核心流程：
    1. 温度缩放
    2. 三层防护过滤
    3. Token解码和验证
    4. 等价Token合并
    5. 多Token答案标准化
    
    Args:
        logits_data: Logits数据（从硬标签生成时获取）
        question: 问题文本
        primary_answer: 主答案（硬标签）
    
    Returns:
        答案概率分布字典
    """
    distribution = {}
    
    # ===== Step 1: 提取第一个Token的Logits =====
    if 'top_k_indices' in logits_data and 'top_k_values' in logits_data:
        token_indices = logits_data['top_k_indices']
        token_logits = logits_data['top_k_values']  # 现在是logits，不是概率
        
        # 处理不同维度
        if token_indices.dim() == 1:
            first_token_indices = token_indices
            first_token_logits = token_logits
        elif token_indices.dim() == 2:
            first_token_indices = token_indices[0]
            first_token_logits = token_logits[0]
        else:
            first_token_indices = token_indices[0, 0]
            first_token_logits = token_logits[0, 0]
        
        # ===== Step 2: 温度缩放 =====
        # 标准公式：soft_probs = softmax(logits / temperature)
        scaled_logits = first_token_logits / self.temperature
        
        # ===== Step 3: 三层防护过滤 =====
        valid_token_mask = torch.zeros_like(scaled_logits, dtype=torch.bool)
        primary_answer_lower = primary_answer.lower() if primary_answer else None
        
        # 🔧 获取硬标签对应的token ID（第二层保护）
        hard_label_token_ids = set()
        if primary_answer_lower:
            try:
                encoded_ids = self.teacher.tokenizer.encode(primary_answer_lower, add_special_tokens=False)
                hard_label_token_ids = set(encoded_ids)
                self.logger.debug(f"[Hard Label Protection] Primary answer '{primary_answer}' -> token IDs: {hard_label_token_ids}")
            except Exception as e:
                self.logger.warning(f"[Hard Label Protection] Failed to encode primary answer: {e}")
        
        # 🔧 第一层：黑名单过滤
        for i, token_id in enumerate(first_token_indices):
            try:
                token_str = self.teacher.tokenizer.decode([token_id.item()]).strip()
                
                # 🔧 第二层：硬标签保护（安全网）
                # 无论黑名单如何，强制将hard_label_id加入放行列表
                if token_id.item() in hard_label_token_ids:
                    valid_token_mask[i] = True
                    self.logger.debug(f"[Hard Label Protection] ✓ Reserved hard label token: '{token_str}'")
                    continue
                
                # 🔧 第一层：黑名单（核心防线）
                # 使用VQATokenFilter判断是否有效
                if self.token_filter and self.token_filter.is_valid_token(token_str, question):
                    valid_token_mask[i] = True
                else:
                    self.logger.debug(f"[Blacklist Filter] ✗ Filtered out: '{token_str}'")
            except Exception as e:
                self.logger.warning(f"[Blacklist Filter] Failed to decode token {token_id}: {e}")
        
        # 🔧 第三层：Top-K兜底（多样性保障）
        min_valid_tokens = 10
        num_valid = valid_token_mask.sum().item()
        
        if num_valid < min_valid_tokens and num_valid > 0:
            # 有有效token，但数量不足，需要补充
            self.logger.info(f"[Top-K Fallback] Only {num_valid} tokens remaining, supplementing...")
            
            # 计算原始概率分布
            token_probs_raw = torch.softmax(scaled_logits, dim=-1)
            
            # 按概率排序，取Top-100作为候选集
            top_k_fallback = min(self.top_k * 2, len(first_token_indices))
            top_k_indices = torch.topk(token_probs_raw, top_k_fallback).indices
            
            # 补充逻辑：从Top-K中添加未被过滤的token
            for idx in top_k_indices:
                if not valid_token_mask[idx]:
                    try:
                        token_id = first_token_indices[idx]
                        token_str = self.teacher.tokenizer.decode([token_id.item()]).strip()
                        
                        # 使用较宽松的过滤策略
                        if self.token_filter and self.token_filter.is_valid_token(token_str, None):
                            valid_token_mask[idx] = True
                            
                            if valid_token_mask.sum().item() >= min_valid_tokens:
                                break
                    except Exception as e:
                        self.logger.warning(f"[Top-K Fallback] Failed to decode token: {e}")
        
        # ===== Step 4: 应用Mask到Logits =====
        # 将无效token的logits设为-1e9（softmax后会接近0）
        scaled_logits_filtered = scaled_logits.clone()
        scaled_logits_filtered[~valid_token_mask] = -1e9
        
        # 计算softmax得到概率
        token_probs = torch.softmax(scaled_logits_filtered, dim=-1)
        
        # ===== Step 5: 解码Token并构建分布 =====
        items = []
        for idx, prob_val in zip(first_token_indices, token_probs):
            # 过滤掉概率太小的
            if prob_val < 0.001:
                continue
            
            try:
                word = self.teacher.tokenizer.decode([idx.item()])
                word = word.strip().lower()
                
                # 过滤特殊token
                if word and word not in ['<s>', '</s>', '<pad>', ...]:
                    # 验证token完整性（防止BPE碎片）
                    try:
                        re_encoded_ids = self.teacher.tokenizer.encode(word, add_special_tokens=False)
                        
                        # 如果重新编码后只得到一个token ID，且与原ID一致，则认为是完整单词
                        if len(re_encoded_ids) == 1 and re_encoded_ids[0] == idx.item():
                            if len(word) > 1 or word.isdigit():
                                items.append((word, float(prob_val)))
                        else:
                            # 是BPE碎片，跳过（除非是硬标签）
                            if primary_answer_lower and word == primary_answer_lower:
                                items.append((word, float(prob_val)))
                    except Exception as e:
                        if len(word) > 1 or word.isdigit():
                            items.append((word, float(prob_val)))
            except Exception:
                pass
        
        # ===== Step 6: 合并相同词的概率 =====
        word_probs = {}
        for word, prob in items:
            if word in word_probs:
                word_probs[word] += prob
            else:
                word_probs[word] = prob
        
        # ===== Step 7: 多Token答案标准化 =====
        # 问题："hotdog"被分词成["hot", "dog"]
        # 解决：将第一个token的概率映射到完整答案
        if primary_answer_lower:
            try:
                primary_token_ids = self.teacher.tokenizer.encode(primary_answer_lower, add_special_tokens=False)
                
                if len(primary_token_ids) > 1:
                    # 是多Token答案，获取第一个token
                    first_token = self.teacher.tokenizer.decode([primary_token_ids[0]]).strip().lower()
                    
                    # 如果第一个token在分布中，将其概率转移到完整答案
                    if first_token in word_probs and primary_answer_lower not in word_probs:
                        prob = word_probs.pop(first_token)
                        word_probs[primary_answer_lower] = prob
                        self.logger.debug(
                            f"[Multi-Token Normalization] Mapped '{first_token}' -> '{primary_answer_lower}'"
                        )
            except Exception as e:
                self.logger.warning(f"[Multi-Token Normalization] Failed: {e}")
        
        # 构建 distribution
        for word, prob in word_probs.items():
            distribution[word] = prob
    
    # ===== Step 8: 归一化分布 =====
    if distribution:
        total_prob = sum(distribution.values())
        if total_prob > 0:
            distribution = {k: v / total_prob for k, v in distribution.items()}
    
    # ===== Step 9: 合并等价token的概率 =====
    if distribution and self.token_filter:
        distribution = self.token_filter.merge_equivalent_tokens(distribution)
    
    # ===== Step 10: 字符串层级二次过滤 =====
    if distribution and self.token_filter:
        distribution = self.token_filter.filter_distribution(
            distribution=distribution,
            question=question,
            primary_answer=primary_answer,
            min_prob=0.001,
            max_answers=50
        )
    
    return distribution
```

## 5. 思维链生成详解

### 4.1 定义

**思维链（CoT）**是教师模型生成答案的**推理过程**，展示"如何思考"。

### 4.2 生成流程

```
┌─────────────────────────────────────────────────────────┐
│ Step 1: 输入准备                                         │
│   - 图像路径                                             │
│   - 问题文本                                             │
│   - 硬标签答案（用于限定答案范围）                        │

                          ↓
┌─────────────────────────────────────────────────────────┐
```

### 4.3 代码实现

**位置**: `src/models/teacher_model.py:420-520`

```python
def inference_vqa_with_cot(self, image, question, primary_answer=None, allowed_answers=None):
    """
    执行VQA推理，生成思维链
    
    Args:
        image: 图像路径
        question: 问题文本
        primary_answer: 主答案（用于限定范围）
        allowed_answers: 允许的答案列表（从软标签提取）
    
    Returns:
        {
            'cot_reasoning': {
                'structured_reasoning': {
                    'observation': '...',
                    'analysis': '...',
                    'conclusion': '...'
                },
                'quality_metrics': {
                    'is_valid': True
                }
            }
        }
    """
    # Step 1: 构建CoT Prompt
    cot_prompt = self._construct_cot_prompt(
        question=question,
        primary_answer=primary_answer,
        allowed_answers=allowed_answers
    )
    
    # Prompt示例:
    """
    <image>
    
    Question: What is the color of the water?
    
    Analyze the image and answer the question. Follow this format:
    
    Observation: Describe what you see in the image - the main objects, their colors, positions, quantities, and key visual features. Be specific and factual.
    
    Analysis: Analyze how these observations relate to the question. Compare visual evidence and rule out uncertain details.
    
    Conclusion: Summarize the reasoning and provide the Final Answer matching one of these allowed answers: green, blue, gray, white, clear.
    
    Final Answer must be one word from the allowed answers list.
    """
    
    # Step 2: 模型推理
    inputs = self._prepare_inputs(image, cot_prompt)
    
    # 使用较低温度，确保推理过程稳定
    outputs = self._generate(
        inputs,
        temperature=0.1,
        max_new_tokens=512
    )
    
    # Step 3: 提取推理文本
    generated_tokens = outputs.sequences[0]
    reasoning_text = self.tokenizer.decode(generated_tokens, skip_special_tokens=True)
    
    # 结果示例:
    """
    Observation: The image shows a body of water in the center. The water has a distinct greenish color, 
    likely due to algae or vegetation. The surrounding environment includes trees with green leaves 
    that are reflected in the water.
    
    Analysis: The question asks about the color of the water. The visual evidence clearly shows the 
    water has a green color. The green reflection from the trees might contribute to this appearance, 
    but the water itself appears naturally green. Other colors like blue or gray are not prominent.
    
    Conclusion: Based on the visual evidence, the water color is predominantly green.
    Final Answer: green
    """
    
    # Step 4: 解析推理过程
    structured_reasoning = self._parse_cot_output(reasoning_text)
    
    # 解析结果:
    # {
    #     'observation': 'The image shows a body of water...',
    #     'analysis': 'The question asks about the color...',
    #     'conclusion': 'Based on the visual evidence...',
    # }
    
    # Step 5: 质量评估
    quality_metrics = self._evaluate_cot_quality(structured_reasoning)
    
    return {
        'cot_reasoning': {
            'structured_reasoning': structured_reasoning,
            'quality_metrics': quality_metrics
        }
    }
```

## 6. 学生模型训练如何使用

### 5.1 三种标签的组合使用

```python
class StudentModelTrainer:
    """学生模型训练器"""
    
    def __init__(self, student_model, teacher_data):
        self.student = student_model
        self.data = teacher_data  # 包含三种标签的数据
        
        # 损失权重
        self.hard_label_weight = 1.0
        self.soft_label_weight = 2.0  # 软标签更重要（知识蒸馏核心）
        self.cot_weight = 0.5
    
    def train_step(self, batch):
        """
        一个训练步骤
        
        Args:
            batch: 包含image, question, hard_label, soft_label, cot
        """
        image = batch['image']
        question = batch['question']
        
        # ===== 1. 硬标签损失 =====
        hard_label = batch['hard_label']
        student_logits = self.student(image, question)
        
        hard_loss = self.cross_entropy_loss(
            student_logits,
            hard_label['answer']
        )
        
        # ===== 2. 软标签损失（知识蒸馏核心）=====
        soft_label = batch['soft_label']
        teacher_probs = soft_label['answer_distribution']
        
        # 学生输出转换为概率（使用相同的温度）
        temperature = soft_label['temperature']
        student_probs = torch.softmax(student_logits / temperature, dim=-1)
        
        # KL散度损失
        soft_loss = self.kl_divergence_loss(
            student_probs,
            teacher_probs
        )
        
        # ===== 3. CoT损失 =====
        if 'cot_reasoning' in batch:
            cot = batch['cot_reasoning']
            reasoning_text = cot['structured_reasoning']
            
            # 学生生成推理过程
            student_reasoning = self.student.generate_reasoning(image, question)
            
            # 序列损失
            cot_loss = self.sequence_loss(student_reasoning, reasoning_text)
        else:
            cot_loss = 0
        
        # ===== 4. 总损失 =====
        total_loss = (
            self.hard_label_weight * hard_loss +
            self.soft_label_weight * soft_loss +
            self.cot_weight * cot_loss
        )
        
        # 反向传播
        total_loss.backward()
        self.optimizer.step()
        
        return {
            'total_loss': total_loss.item(),
            'hard_loss': hard_loss.item(),
            'soft_loss': soft_loss.item(),
            'cot_loss': cot_loss.item() if cot_loss else 0
        }
```

### 5.2 训练流程图

```
输入数据
  │
  ├── image
  ├── question
  │
  ├── hard_label (确定性答案)
  │     ↓
  │   计算交叉熵损失 → L_hard
  │   作用: 学习"正确答案"
  │
  ├── soft_label (概率分布)
  │     ↓
  │   计算KL散度损失 → L_soft (蒸馏核心)
  │   作用: 学习"答案间关系"（暗知识）
  │
  └── cot_reasoning (推理步骤)
        ↓
      计算序列损失 → L_cot
      作用: 学习"如何推理"
  
  总损失 = α·L_hard + β·L_soft + γ·L_cot
         (通常: α=1.0, β=2.0, γ=0.5)
  
  反向传播 → 更新学生模型
```

### 5.3 损失函数详解

#### 硬标签损失（交叉熵）

```python
def cross_entropy_loss(student_logits, target_answer):
    """
    硬标签损失：让学生输出正确答案
    
    公式: L_hard = -log(P(target_answer))
    """
    probs = torch.softmax(student_logits, dim=-1)
    target_token_id = tokenizer.encode(target_answer)[0]
    loss = -torch.log(probs[target_token_id])
    return loss
```

#### 软标签损失（KL散度）

```python
def kl_divergence_loss(student_probs, teacher_probs):
    """
    软标签损失：让学生学习教师的概率分布
    
    公式: L_soft = Σ teacher_prob · log(teacher_prob / student_prob)
    
    这是知识蒸馏的核心！
    """
    loss = torch.sum(
        teacher_probs * torch.log(teacher_probs / (student_probs + 1e-10))
    )
    return loss
```

#### CoT损失（序列到序列）

```python
def sequence_loss(student_reasoning, teacher_reasoning):
    """
    CoT损失：让学生生成相似的推理过程
    
    公式: L_cot = CrossEntropy(student_tokens, teacher_tokens)
    """
    student_tokens = tokenizer.encode(student_reasoning)
    teacher_tokens = tokenizer.encode(teacher_reasoning)
    loss = cross_entropy(student_tokens, teacher_tokens)
    return loss
```

## 8. 常见问题与修复

### 7.1 多Token答案丢失问题

**问题**：
- 答案`"hotdog"`被分词成`["hot", "dog"]`
- 软标签分布中只有第一个token `"hot"`
- 完整答案`"hotdog"`不在分布中

**原因**：
- Qwen分词器将多音节词切分成多个token
- 软标签基于第一个token的logits生成
- 第一个token不等于完整答案

**修复**：
- 检测答案是否是多Token
- 将第一个token的概率映射到完整答案
- 代码位置：[src/distillation/vqa_soft_label_gen.py:442-470](src/distillation/vqa_soft_label_gen.py:442-470)

**修复代码**：
```python
# 检查答案是否是多Token
primary_token_ids = tokenizer.encode("hotdog")  # [hot_id, dog_id]

if len(primary_token_ids) > 1:
    # 获取第一个token
    first_token = tokenizer.decode([primary_token_ids[0]])  # "hot"
    
    # 将第一个token的概率映射到完整答案
    if first_token in word_probs and "hotdog" not in word_probs:
        prob = word_probs.pop(first_token)
        word_probs["hotdog"] = prob
```

## 11. 总结

### 三种标签对比

| 维度 | 硬标签 | 软标签 | CoT |
|------|--------|--------|-----|
| **内容** | 正确答案 | 概率分布 | 推理步骤 |
| **格式** | 单个答案 | {answer: prob} | 步骤序列 |
| **知识** | 确定性 | 不确定性（暗知识） | 推理过程 |
| **损失** | 交叉熵 | KL散度 | 序列损失 |
| **权重** | 1.0 | 2.0 ⭐ | 0.5 |
| **作用** | 学习答案 | 学习分布 ⭐ | 学习推理 |
| **推理次数** | 1次（共用） | 1次（共用） | 1次（独立） |

### 推理策略总结

| 策略 | 推理次数 | 总耗时 | 性能提升 | 推荐场景 | 关键特点 |
|------|---------|--------|---------|---------|---------|
| **一次推理** | 1次 | 290ms | 基线 | 快速原型 | 效率最高，质量降低 |
| **两次推理+缓存** ⭐⭐⭐⭐⭐ | 2次 | **630ms** | **+19%** | 生产环境 | 质量+效率最佳，视觉特征缓存 |
| **两次推理（无缓存）** | 2次 | 780ms | 基线 | 已淘汰 | 无优化，已被缓存方案取代 |
| **三次推理** | 3次 | >1000ms | - | 实验研究 | 完全独立，一致性差 |

### 关键要点

1. **两次推理+缓存是最佳策略** ⭐：质量、效率、一致性的最佳平衡
2. **视觉特征缓存优化**：第二次推理节省150ms，总体加速19%
3. **硬标签和软标签同源**：来自同一次推理，确保一致性
4. **CoT需要第二次推理**：不同的参数、长度、答案范围限定
5. **软标签最重要**：包含"暗知识"，是知识蒸馏的核心
6. **硬标签保底**：确保模型学到正确答案
7. **温度缩放**：软标签必须使用温度缩放（本项目T=4）
8. **多Token答案**：需要特殊处理，将第一个token映射到完整答案
