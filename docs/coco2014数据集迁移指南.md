# COCO 2014 数据集迁移指南

## COCO 2014 vs 2017 主要差异

### 数据集规模差异

| 数据集 | 训练集 | 验证集 | 说明 |
|--------|--------|--------|------|
| **COCO 2014** | 82,783张 | 40,504张 | 更大的验证集 |
| **COCO 2017** | 118,287张 | 5,000张 | 更大的训练集，更小的验证集 |

### 文件命名差异

| 文件类型 | COCO 2014 | COCO 2017 |
|----------|-----------|-----------|
| **Caption标注** | `captions_val2014.json` | `captions_val2017.json` |
| **Instance标注** | `instances_val2014.json` | `instances_val2017.json` |
| **VQA问题** | `v2_mscoco_val2014_questions.json` | `v2_mscoco_val2017_questions.json` |
| **图像目录** | `val2014/` | `val2017/` |

### VQA数据差异

- **COCO 2014**: VQA v2.0使用val2014验证集（40,504张图像）
- **COCO 2017**: VQA v2.0使用val2017验证集（5,000张图像）

### 3. 代码文件更新（可选，代码已兼容）

代码已经设计为支持任意split名称，所以**不需要修改代码**。只需确认以下文件能正确处理2014数据：

#### `src/data/coco_loader.py`

```python
# 已兼容任意split名称
def initialize(self, split: str = "val2017") -> None:
    """
    Args:
        split: Dataset split (train2017, val2017, train2014, val2014)  # ← 已支持
    """
    # Load caption annotations
    caption_ann_file = self.annotations_root / f"captions_{split}.json"
    # 对于val2014，会加载 captions_val2014.json ✅

    # Load instance annotations
    instance_ann_file = self.annotations_root / f"instances_{split}.json"
    # 对于val2014，会加载 instances_val2014.json ✅

    # Load VQA annotations
    vqa_ann_file = self.annotations_root / f"v2_mscoco_{split}_questions.json"
    # 对于val2014，会加载 v2_mscoco_val2014_questions.json ✅
```

#### `src/data/coco_loader.py` - 图像路径处理

```python
def get_image_path(self, image_id: int, split: str = "val2017") -> Optional[Path]:
    """
    Get image file path for given image ID.

    注意：2014和2017的图像文件名格式略有不同：
    - 2014: COCO_val2014_000000001523.jpg
    - 2017: 000000001523.jpg
    """
    img_info = self.images_data[image_id]
    file_name = img_info.get('file_name')

    # 尝试多个可能的位置
    possible_paths = [
        self.images_root / split / file_name,  # ← 会自动处理val2014目录
        self.images_root / file_name,
        self.coco_root / split / file_name,
    ]

    for path in possible_paths:
        if path.exists():
            return path
```

**关键点**：代码已经兼容，只要配置文件正确设置split名称即可。

#### COCO 2014图像文件名格式

#### 代码已自动处理

`coco_loader.py`会从标注文件中读取`file_name`字段，自动适配：

```python
# 在标注文件中：
{
  "images": [
    {
      "id": 1523,
      "file_name": "COCO_val2014_000000001523.jpg"  # ← 2014格式
      # 或 "000000001523.jpg"  ← 2017格式
    }
  ]
}

# 代码自动读取：
img_info = self.images_data[image_id]
file_name = img_info.get('file_name')  # ← 自动获取正确格式
```

### 6. 测试配置是否正确

#### 快速验证脚本

创建一个测试脚本验证数据加载：

```python
# scripts/test_coco2014_loading.py
import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).parent.parent / "src"))

from data import COCODataLoader
from utils import ConfigManager

def test_coco2014_loading():
    """测试COCO 2014数据集加载"""

    # 加载配置
    config = ConfigManager('configs/default.yaml')

    # 检查配置
    print(f"Annotations root: {config.get('data.annotations_root')}")
    print(f"Images root: {config.get('data.images_root')}")
    print(f"Val split: {config.get('data.val_split')}")

    # 初始化数据加载器
    loader = COCODataLoader(config)

    # 测试加载val2014
    print("\nInitializing COCO 2014 val split...")
    loader.initialize('val2014')

    # 获取摘要
    summary = loader.get_annotation_summary()
    print("\nDataset summary:")
    print(f"  Total images: {summary['total_images']}")
    print(f"  Images with captions: {summary['images_with_captions']}")
    print(f"  Images with instances: {summary['images_with_instances']}")
    print(f"  Images with VQA: {summary['images_with_vqa']}")
    print(f"  Total captions: {summary['total_captions']}")
    print(f"  Total instances: {summary['total_instances']}")
    print(f"  Total VQA questions: {summary['total_vqa_questions']}")
    print(f"  Categories: {summary['num_categories']}")

    # 测试图像加载
    if summary['total_images'] > 0:
        test_image_id = list(loader.images_data.keys())[0]
        image_path = loader.get_image_path(test_image_id, 'val2014')

        if image_path:
            print(f"\n✅ Test image loaded successfully:")
            print(f"  Image ID: {test_image_id}")
            print(f"  Path: {image_path}")
        else:
            print(f"\n❌ Failed to load image {test_image_id}")

    print("\n✅ COCO 2014 loading test complete!")

if __name__ == "__main__":
    test_coco2014_loading()
```
