## 核心概念

### 什么是候选集？

候选集是VQA答案的预定义集合，用于：
- **约束答案空间**：将无限的答案空间限制在合理的范围内
- **降噪**：过滤掉不相关、不合理、错误的答案
- **提升效率**：在小规模候选集上计算分布，而非全词表

### 传统方案 vs 新方案

| 对比项 | 传统方案（单一候选集） | 新方案（分场景候选集） |
|--------|----------------------|----------------------|
| **候选集** | 固定候选集（1873个答案） | 分场景独立候选集 ✅ |
| **问题感知** | 所有问题都用同一候选集 | 根据问题类型动态选择 ✅ |
| **噪声控制** | 噪声多、效率低 | 高质量、高效率 ✅ |
| **答案数** | 1873个（所有问题） | 21-1873个（按场景） ✅ |

### 场景示例

```
计数问题 → count候选集（21个答案）：zero, one, two, three, ...
颜色问题 → color候选集（24个答案）：red, green, blue, yellow, ...
二元问题 → binary候选集（2个答案）：yes, no
其他问题 → other候选集（1873个答案）：所有答案
```

## 数据源详解

### 1. VQA人工标注（底层，最高优先级）

**文件**：`data/coco/annotations/v2_mscoco_train2014_annotations.json`

**为什么需要？**
- VQA标注是**人工众包答案**，直接对应问题-答案对
- 每个问题有**10个众包答案**，覆盖了常见和合理的答案
- 这是候选集的**主要来源**

**提取方式**：
```python
for ann in annotations:
    # 每个问题有10个众包答案
    if 'answers' in ann:
        for ans_obj in ann['answers']:
            raw_answer = ans_obj.get('answer', '').strip()
            
            # 应用全局标准清洗
            cleaned_answer = global_standard_clean(raw_answer)
            if cleaned_answer:
                answers.add(cleaned_answer)
```

**示例数据**：
```json
{
  "annotations": [
    {
      "question_id": 123,
      "image_id": 456,
      "answers": [
        {"answer": "dog", "answer_confidence": "yes"},
        {"answer": "cat", "answer_confidence": "maybe"},
        ...  // 10个众包答案
      ]
    }
  ]
}
```

### 2. COCO Caption（中层，补充长尾视觉答案）

**文件**：`data/coco/annotations/captions_train2014.json`

**为什么需要Caption？**

VQA标注有局限性：
- ❌ VQA问题类型有限（主要是计数、颜色、二元、其他）
- ❌ VQA答案可能遗漏某些**长尾视觉概念**
- ✅ Caption是对图像的完整描述，包含更多视觉细节

**例如**：
```
VQA问题："What animal is this?" → 答案："dog"
Caption: "A fluffy golden retriever playing with a red ball in the park."

Caption补充了：
- 物体细节：golden retriever（品种）
- 颜色：red（球的属性）
- 场景：park
- 动作：playing
```

**提取方式**：
```python
for ann in annotations:
    caption = ann.get('caption', '').lower().strip()
    
    # 简单分词
    words = caption.split()
    
    for word in words:
        # 清理标点符号
        word = re.sub(r'[^\w]', '', word).strip()
        
        # 提取4类关键词：
        if cleaned_word in colors:
            keywords.add(cleaned_word)  # 颜色
        elif cleaned_word in numbers:
            keywords.add(cleaned_word)  # 数字
        elif cleaned_word in positions:
            keywords.add(cleaned_word)  # 方位
        elif len(cleaned_word) > 2 and cleaned_word.isalpha():
            keywords.add(cleaned_word)  # 名词
```

### 4. COCO Instance（场景映射，Stage 2）

**文件**：`data/coco/annotations/instances_train2014.json`

**Instance的作用不是用来构建候选集池，而是用来做场景映射！**

**为什么需要？**
- VQA标注只有问题和答案，**没有场景信息**
- 需要知道每张图像属于哪个场景，才能做分场景候选集

**如何使用？**
```python
# 1. 加载instances标注
data = load_coco_instances(instances_file)

# 2. 构建类别映射：category_id → supercategory
categories = build_category_mapping(data)
# 示例：
# {
#   1: {'name': 'person', 'supercategory': 'person'},
#   2: {'name': 'bicycle', 'supercategory': 'vehicle'},
#   ...
# }

# 3. 判定每张图像的主场景
for image in images:
    image_id = image['id']
    annotations = image_annotations[image_id]
    
    # 统计该图像所有实例的场景
    scene_counter = Counter()
    for ann in annotations:
        cat_id = ann['category_id']
        supercategory = categories[cat_id]['supercategory']
        scene_counter[supercategory] += 1
    
    # 出现最多的场景作为主场景
    primary_scene = scene_counter.most_common(1)[0][0]
```

```python
]
```

## 修复方案

### 问题诊断

**问题1：脏词混入 object 场景**
- 现象：person 场景包含 "red", "left", "two" 等脏词
- 原因：缺少全局前置分流，脏词直接混入 object

**问题2：场景白名单过滤不严格**
- 现象：脏词通过白名单过滤
- 原因：允许颜色/方位/数字通过白名单

**问题3：复合短语未拦截**
- 现象："orange dog" 等复合短语通过
- 原因：缺少全局黑名单二次拦截

**问题4：流程执行顺序错误**
- 现象：分组后再分流
- 原因：流程设计错误

---

### 四步修复方案

#### 步骤1：全局前置分流（Stage 1）

**修复位置**：`tools/candidate/stage1_build_global_pool.py`

**核心改动**：
```python
def categorize_answers(answers: Set[str]) -> Dict[str, List[str]]:
    """
    全局前置分流（从源头杜绝脏词进入 object）
    """
    # 预定义三类脏词集合
    color_set = {"black", "white", "red", "blue", "green", "orange", ...}
    location_set = {"left", "right", "middle", "front", "back", ...}
    number_set = {"0", "1", "2", "zero", "one", "two", ...}
    
    candidates = {
        "color": [],
        "location": [],
        "number": [],
        "yesno": [],
        "object": []
    }
    
    for ans in answers:
        ans_lower = ans.strip().lower()
        
        # 分流逻辑
        if ans_lower in color_set:
            candidates["color"].append(ans_lower)
        elif ans_lower in location_set:
            candidates["location"].append(ans_lower)
        elif ans_lower in number_set:
            candidates["number"].append(ans_lower)
        elif ans_lower in yesno_set:
            candidates["yesno"].append(ans_lower)
        else:
            # 剩下的进入 object 候选池
            candidates["object"].append(ans_lower)
    
    return candidates
```

**效果**：
```
分流前：所有答案混在一起（1873个）
分流后：
  - color: 20个
  - location: 18个
  - number: 42个
  - yesno: 2个
  - object: 1500个
```

---

#### 步骤2：场景白名单强过滤（Stage 3）

**修复位置**：`tools/candidate/stage3_scene_closure.py`

**核心改动**：
```python
def filter_by_objects(object_candidates: List[str], scene: str) -> List[str]:
    """
    场景白名单强过滤（兜底清理残留脏词）
    """
    scene_filter_cfg = SCENE_FILTER_CONFIG.get(scene, {})
    white_list = scene_filter_cfg.get('white_list', set())
    
    # 脏词集合
    color_set = {"black", "white", "red", "blue", ...}
    location_set = {"left", "right", "middle", ...}
    number_set = {"zero", "one", "two", ...}
    
    filtered = []
    
    for answer in object_candidates:
        answer_lower = answer.lower().strip()
        
        # 白名单强过滤
        if answer_lower not in white_list:
            # 如果是脏词，直接丢弃
            if answer_lower in color_set or answer_lower in location_set or answer_lower in number_set:
                print(f"  ⚠️  清理脏词: '{answer_lower}' 不在场景 '{scene}' 白名单内")
                continue
            # 如果不是脏词，也不在白名单，丢弃
            continue
        
        filtered.append(answer)
    
    return filtered
```

**场景白名单配置**：
```python
SCENE_FILTER_CONFIG = {
    "person": {
        "white_list": {"person", "man", "woman", "child", "baby", "kid", ...},
        "black_list": {"floor", "wall", "room", "house", ...}
    },
    "vehicle": {
        "white_list": {"car", "bus", "truck", "train", "bicycle", ...},
        "black_list": {"store", "shop", "road", "street", ...}
    },
    ...
}
```

---

#### 步骤3：全局黑名单过滤（二次拦截）

**修复位置**：`tools/candidate/stage3_scene_closure.py`

**核心逻辑**：
```python
# 在 filter_by_objects 中实现
for answer in object_candidates:
    answer_lower = answer.lower().strip()
    
    # 检查是否包含黑名单词汇
    answer_words = set(answer_lower.split())
    if answer_words & black_list:
        continue
    
    # 检查是否是脏词（二次拦截）
    if answer_lower in color_set or answer_lower in location_set or answer_lower in number_set:
        print(f"  ⚠️  清理脏词: '{answer_lower}'")
        continue
```

---

#### 步骤4：修正流水线执行顺序

**正确流程**：
```
采集答案 → 全局清洗 → 全局前置分流 → 频次过滤 → 输出分类候选集
```

**Stage 3 流程**：
```
1. 加载分类候选集（color/location/number/yesno/object）
2. 基础答案直接作为独立场景
3. object 候选集进行场景分组 + 白名单强过滤
4. 输出分场景候选集
```

## 常见问题

### Q1: 为什么需要从 Caption 中提取关键词？

**答**：VQA标注有局限性：
- VQA问题类型有限（主要是计数、颜色、二元、其他）
- VQA答案可能遗漏某些长尾视觉概念
- Caption是对图像的完整描述，包含更多视觉细节

**示例**：
```
VQA问题："What animal is this?" → 答案："dog"
Caption: "A fluffy golden retriever playing with a red ball in the park."

Caption补充了：
- 物体细节：golden retriever（品种）
- 颜色：red（球的属性）
- 场景：park
```

---

### Q2: Instance 的作用是什么？

**答**：Instance **不是用来构建候选集池**，而是用来**映射场景**。

- VQA标注只有问题和答案，没有场景信息
- Instance 包含图像的检测框和类别信息
- 通过统计图像中的物体类别，判定图像属于哪个场景
