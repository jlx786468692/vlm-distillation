## 项目概览

本项目是一个完整的 VLM数据蒸馏清洗管道，包含以下所有组件：

### 项目核心特性

| 特性 | 说明 | 实现状态 |
|------|------|----------|
| **三重标签生成** | 硬标签 + 软标签 + 思维链 | ✅ 100% |
| **多任务支持** | VQA、Captioning、Detection | ✅ 100% |
| **数据清洗** | 异常检测 + 质量评分 + 过滤修复 | ✅ 100% |
| **一键运行** | 整合蒸馏+清洗+验证流程 | ✅ 100% |
| **详细报告** | 清洗统计 + 流程报告 | ✅ 100% |

## 整体流程设计

### 三阶段流程概览

| 阶段 | 名称 | 输入 | 处理 | 输出 | 实现状态 |
|------|------|------|------|------|----------|
| **阶段1** | 数据构造 | COCO数据集 | TeacherModel推理生成三重标签 | merged/*.json | ✅ 100% |
| **阶段2** | 数据清洗 | merged/*.json | DataCleaner异常检测+质量评分+清洗 | cleaned/*.json | ✅ 100% |
| **阶段3** | 学生训练 | cleaned/*.json | 学生模型训练 | 小型VLM模型 | ⏳ 待实现 |

### 阶段1: 数据构造流程

#### 输入数据

| 数据类型 | 文件路径 | 内容说明 |
|----------|----------|----------|
| **图像文件** | `val2017/*.jpg` | COCO验证集图像 |
| **VQA问题** | `annotations/v2_mscoco_val2017_questions.json` | 视觉问答问题 |
| **标题标注** | `annotations/captions_val2017.json` | 图像描述标注 |
| **检测标注** | `annotations/instances_val2017.json` | 目标检测框标注 |

#### TeacherModel处理

| 任务 | 输入 | 输出 | 用途 |
|------|------|------|------|
| **VQA** | 图像 + 问题 | answer + confidence + logits | 视觉问答 |
| **Captioning** | 图像 | captions + distributions | 图像描述 |
| **Detection** | 图像 | objects + bbox + logits | 目标检测 |

#### 三重标签生成

| 标签类型 | 内容 | 特点 | 训练用途 |
|----------|------|------|----------|
| **硬标签** | 最终预测结果 + 置信度分数 | 直接明确 | 监督训练 (CrossEntropy) |
| **软标签** | 温度缩放概率分布 (T=2.0) | 暗知识保留 | KL散度损失 |
| **CoT** | 结构化推理过程 | 步骤化推理 | 推理增强训练 |

### 阶段2: 数据清洗流程

#### 数据质量问题类型

| 问题类型 | 检测条件 | 代码位置 | 处理方式 |
|----------|----------|----------|----------|
| `low_confidence` | confidence < 0.5 | 第214-222行 | 标记异常 |
| `invalid_answers` | 'unknown', 'N/A', 空 | 第224-232行 | 规则2移除 |
| `empty_results` | 无caption/检测结果 | 第286-338行 | 规则3移除 |
| `bbox_anomalies` | bbox超出范围/异常 | 第342-396行 | 自动修复 |
| `cot_low_quality` | logical_flow < 0.5 | 第254-276行 | 规则6移除 |
| `length_anomalies` | 答案长度 < 3 或 > 100 | 第235-251行 | 标记异常 |
| `format_errors` | bbox格式错误/字段缺失 | 第346-352行 | 规则4移除 |

#### 8步清洗流程

| 步骤 | 功能 | 处理内容 |
|------|------|----------|
| **Step 1** | 加载JSON文件 | 读取所有 outputs/merged/*.json |
| **Step 2** | 异常检测 | 7种异常类型并行检测 |
| **Step 3** | 质量评分 | 0-100分综合评分系统 |
| **Step 4** | 应用清洗规则 | 6条自动移除规则 |
| **Step 5** | 数据去重 | 答案标准化 + 重复标记 |
| **Step 6** | 数据修复 | bbox裁剪 + 字段补全 |
| **Step 7** | 生成清洗报告 | 统计 + 异常 + 质量 + 建议 |
| **Step 8** | 保存清洗结果 | cleaned/ + removed/ + report |

#### 质量评分系统（0-100分）

| 评分维度 | 分数范围 | 评分标准 | 权重 |
|----------|----------|----------|------|
| **硬标签质量** | 0-40分 | 置信度(30分) + 答案完整性(10分) | 40% |
| **软标签质量** | 0-20分 | 温度合理性(10分) + 分布完整性(10分) | 20% |
| **CoT质量** | 0-30分 | 逻辑流畅度(15分) + 步骤数(15分) | 30% |
| **任务加分** | 0-5分 | VQA有效答案/Caption多样性/Detection完整性 | 5% |

#### 清洗规则（6条）

| 规则编号 | 触发条件 | 处理方式 |
|----------|----------|----------|
| **规则1** | quality_score < 30 | 移除 |
| **规则2** | invalid_answer存在 | 移除 |
| **规则3** | empty_result存在 | 移除 |
| **规则4** | format_error存在 | 移除 |
| **规则5** | 多任务低置信度(≥2) | 移除 |
| **规则6** | CoT严重质量问题 | 移除 |

### 阶段3: 学生模型训练

| 输入数据 | 用途 | 损失函数 |
|----------|------|----------|
| **硬标签** | 监督训练 | CrossEntropy Loss |
| **软标签** | 知识蒸馏 | KL Divergence Loss |
| **CoT** | 推理增强 | Reasoning Enhancement Loss |

## 核心模块详解

### 模型接口模块 (src/models/)

| 模块 | 功能 | 核心方法 |
|------|------|----------|
| `teacher_model.py` | 教师模型接口 | `inference_vqa()`, `inference_captioning()` |
| `student_model.py` | 学生模型接口 | `train()`, `inference()` |

| 模块 | 功能 | 输出格式 |

| 模块 | 功能 | 代码行数 |

| 方法 | 功能 | 返回值 |

| `_compute_quality_scores()` | 质量评分 | 分数字典 |

## 使用方式

```bash
# 运行完整流程（推荐）
python scripts/run_full_pipeline.py --samples 5000

# 仅运行特定步骤
python scripts/run_full_pipeline.py --steps distillation cleaning

    --samples 1000 \
    --tasks vqa captioning \
    --min-quality 40 \
```

## 📝 总结

### 流程总结

整个流程就是：

1. **数据构造**: COCO数据+标注 → TeacherModel → 生成硬标签+软标签+CoT → JSON文件
2. **数据清洗**: JSON文件 → DataCleaner → 异常检测+质量评分+清洗修复 → 清洗后JSON

### 两阶段设计优势

| 阶段 | 目标 | 特点 |
|------|------|------|
| **阶段1** | 生成丰富的蒸馏数据 | 三种监督信号，信息完整 |
| **阶段2** | 确保训练数据的高质量 | 自动清洗，质量可控 |
