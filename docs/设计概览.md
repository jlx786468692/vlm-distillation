## 整体流程设计

### 六步骤流程概览

| 步骤 | 名称 | 输入 | 处理 | 输出 | 实现状态 |
|------|------|------|------|------|----------|
| **Step 1** | 数据蒸馏 | COCO数据集 | TeacherModel推理生成三重标签 | merged/*.json | ✅ 100% |
| **Step 2** | 初始验证 | merged/*.json | 数据完整性、格式检查 | validation_initial.json | ✅ 100% |
| **Step 3** | 数据清洗 | merged/*.json | 异常检测+质量评分+清洗 | cleaned/*.json | ✅ 100% |
| **Step 4** | 最终验证 | cleaned/*.json | 确认清洗效果 | validation_final.json | ✅ 100% |
| **Step 5** | 质量校验 | cleaned/*.json | 深度质量评估，训练前把关 | quality_validation_report.json | ✅ 100% |
| **Step 6** | 可视化 | 所有数据 | 生成对比图表 | PNG图像 | ✅ 100% |

**流程设计说明**:

1. **初始验证**: 快速检查数据完整性和格式正确性（ValidationComparator）
2. **数据清洗**: 根据初始验证发现的问题进行清洗
3. **最终验证**: 验证清洗效果，确认数据改善
4. **质量校验**: 深度质量评估（KL散度、ECE、幻觉检测），判断是否具备训练价值

> ⚠️ **重要**: 质量校验放在清洗后作为最终把关，而不是蒸馏后立即执行。这样可以确保在训练前对清洗后的数据进行深度质量评估。

## 核心模块详解

### 数据处理模块 (src/data/)

| 模块 | 功能 | 核心方法 |
|------|------|----------|
| `coco_loader.py` | COCO数据集加载 | `load_split()`, `get_annotations()` |
| `image_processor.py` | 图像预处理 | `preprocess()`, `resize()` |
| `data_manager.py` | 数据管理 | `batch_process()`, `save_checkpoint()` |

### 蒸馏核心模块 (src/distillation/)

| 模块 | 功能 | 输出格式 |
|------|------|----------|
| `hard_label_gen.py` | 硬标签生成 | `{answer, confidence}` |
| `soft_label_gen.py` | 软标签生成 | `{distribution, T=2.0}` |
| `cot_generator.py` | 思维链生成 | `{raw, steps, quality_metrics}` |
| `distiller.py` | 主蒸馏协调 | 整合三种标签 |

### 数据清洗模块 (src/cleaning/)

| 方法 | 功能 | 返回值 |
|------|------|----------|
| `clean_directory()` | 批量清洗目录 | 清洗报告 |
| `_detect_anomalies()` | 异常检测 | 异常列表 |
| `_compute_quality_scores()` | 质量评分 | 分数字典 |
| `_apply_cleaning_rules()` | 应用清洗规则 | (cleaned, removed) |

### 工具模块 (src/utils/)

| 模块 | 功能 | 说明 |
|------|------|------|
| `config.py` | 配置管理 | 点号访问 (`config.get('teacher.model_name')`) |
| `logger.py` | 日志系统 | 进度追踪 + 错误记录 |
| `data_visualizer.py` | ✨ 可视化 | 4个核心功能 (见下节) |
| `data_quality_analyzer.py` | 数据质量分析 | 置信度/质量分数/CoT统计 |
| `validation_comparator.py` | 验证对比 | 清洗前后效果对比 |

### 导出模块 (src/export/)

| 模块 | 功能 | 输出 |
|------|------|------|
| `json_exporter.py` | JSON导出 | `merged/*.json` (仅此文件夹) |

**重要变更**:
- 移除了 `hard_labels/`, `soft_labels/`, `cot_reasoning/` 文件夹
- 所有数据统一输出到 `merged/` 文件夹

## 使用方式

### 一键运行完整流程

```bash
# 运行完整流程（蒸馏+清洗+可视化）
python scripts/run_full_pipeline.py --samples 100 --enable-visualization

# 仅运行特定步骤
python scripts/run_full_pipeline.py --steps distillation cleaning

# 自定义参数
python scripts/run_full_pipeline.py \
    --samples 1000 \
    --tasks vqa captioning \
    --min-quality 40 \
    --min-confidence 0.6

# 单独运行可视化 (需要指定输入目录)
python scripts/run_full_pipeline.py --steps visualization --enable-visualization \
    --input-dir ./outputs/cleaned/cleaned \
    --before-dir ./outputs/merged

# 测试配置
python scripts/run_full_pipeline.py --dry-run

# 跳过验证步骤
python scripts/run_full_pipeline.py --skip-validation

# 指定输出目录
python scripts/run_full_pipeline.py --output-dir ./my_outputs
```

### Python API使用

```python
from scripts.run_full_pipeline import FullPipelineRunner

# 初始化
runner = FullPipelineRunner('configs/default.yaml')

# 运行完整流程
result = runner.run_full_pipeline(
    max_samples=100,
    tasks=['vqa', 'captioning'],
    min_quality=50.0,
    min_confidence=0.6
)

# 查看结果
print(f"成功: {result['success']}")
print(f"完成步骤: {result['steps_completed']}")
print(f"总耗时: {result['total_duration_seconds']}秒")

# 查看耗时统计
timing = result['timing_stats']
for step, stats in timing.items():
    print(f"{step}: {stats['duration']:.1f}s ({stats['samples']} samples)")
```

## 配置参数

### 命令行参数完整列表

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--config` | 配置文件路径 | `configs/default.yaml` |
| `--samples` | 最大处理样本数 | 配置文件值 |
| `--tasks` | 任务列表 | `[vqa, captioning, detection]` |
| `--steps` | 运行步骤 | `[distillation, cleaning, validation]` |
| `--min-quality` | 清洗最小质量分数 | `50.0` |
| `--min-confidence` | 清洗最小置信度 | `0.6` |
| `--enable-visualization` | 启用可视化 | `False` |
| `--input-dir` | 输入数据目录 | `None` |
