## 1. 项目概述

### 1.1 系统目标

| 目标 | 说明 |
|------|------|
| 知识蒸馏 | 从Qwen2.5-VL-7B生成高质量训练数据 |
| 多任务支持 | VQA、Captioning、Detection |
| 数据清洗 | 异常检测+质量评分+过滤修复 |
| 可视化 | 4个核心图表展示清洗效果 |

### 1.2 技术栈

| 层次 | 技术 |
|------|------|
| 深度学习 | PyTorch 2.0+, Transformers 4.40+ |
| 模型 | Qwen2.5-VL-7B-Instruct |
| 数据集 | COCO 2014 |
| 可视化 | matplotlib (英文标签) |
| 配置 | YAML |

## 4. 关键设计

### 4.1 三重标签生成

| 标签类型 | 内容 | 用途 |
|----------|------|------|
| Hard Label | answer + confidence | 监督训练 |
| Soft Label | distribution (T=2.0) | KL散度损失 |
| CoT | reasoning + steps | 推理增强 |

### 4.2 质量评分系统

| 维度 | 分数 | 权重 |
|------|------|------|
| 硬标签质量 | 0-40 | 40% |
| 软标签质量 | 0-20 | 20% |
| CoT质量 | 0-30 | 30% |
| 任务加分 | 0-10 | 10% |

### 4.3 可视化设计 ✨ 更新

| 图表 | 功能 |
|------|------|
| score_comparison | 质量+置信度对比 (上下两子图) |
| sample_count | Before/After/Removed柱状图 |
| sample_*.png | 样本可视化 (最多10张) |
| pipeline_timing | 步骤耗时折线图 |

## 6. API示例

### 6.1 一键运行

```python
from scripts.run_full_pipeline import FullPipelineRunner

runner = FullPipelineRunner('configs/default.yaml')
result = runner.run_full_pipeline(
    max_samples=100,
    min_quality=50.0,
    min_confidence=0.6
)
```

### 6.2 单独可视化

```python
from src.utils import DataVisualizer

visualizer = DataVisualizer(config, logger)
result = visualizer.visualize_all(
    data_list=cleaned_data,
    before_data=merged_data,
    timing_stats=timing_stats
)
```
