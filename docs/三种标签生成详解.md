## 2. 硬标签生成 (HardLabelGenerator)

### 2.1 实现原理

```python
# Step 1: 构造prompt
prompt = f"Question: {question}\nAnswer concisely:"

# Step 2: 调用模型推理
response = teacher.generate(image, prompt)

# Step 3: 提取结果
answer = response['text']
confidence = response['confidence']  # 从logits提取

# Step 4: 格式化输出
{
    "question": question,
    "answer": answer,
    "confidence": confidence
}
```

### 2.2 输出格式

```json
{
  "hard_label": {
    "question": "What is in the image?",
    "answer": "kitchen",
    "confidence": 0.92,
    "full_response": "The image shows a modern kitchen..."
  }
}
```

## 3. 软标签生成 (SoftLabelGenerator)

### 3.1 实现原理

```python
# Step 1: 获取模型logits
logits = teacher.generate(image, prompt, return_logits=True)

# Step 2: 温度缩放
T = 2.0  # 推荐温度
scaled_logits = logits / T

# Step 3: 计算概率分布
probs = softmax(scaled_logits)

# Step 4: Top-k提取
top_k_probs = get_top_k(probs, k=100)
```

### 3.2 温度参数详解

```
温度T的作用:

T = 1.0 (原始分布):
  kitchen: 0.95, bedroom: 0.03, bathroom: 0.02
  ← 过于尖锐,丢失暗知识

T = 2.0 (推荐):
  kitchen: 0.85, bedroom: 0.10, bathroom: 0.05
  ← 平滑合理,保留暗知识 ✅

T = 5.0 (过平滑):
  kitchen: 0.60, bedroom: 0.25, bathroom: 0.15
  ← 信息丢失
```

### 3.3 输出格式

```json
{
  "soft_label": {
    "answer_distribution": {
      "kitchen": 0.85,
      "bedroom": 0.10,
      "bathroom": 0.05
    },
    "temperature": 2.0,
    "top_k_logits": 100
  }
}
```

## 4. 思维链生成 (CoTGenerator)

### 4.1 实现原理

```python
# Step 1: 构造CoT prompt
cot_prompt = """
Analyze this image step by step to answer: {question}

Please think through:
1. First, identify visual elements...
2. Next, analyze their relationships...
3. Then, consider the context...
4. Finally, provide your answer.

Let's analyze:
"""

# Step 2: 调用模型生成
response = teacher.generate(image, cot_prompt, max_tokens=512)

# Step 3: 结构化解析
steps = extract_reasoning_steps(response['text'])

# Step 4: 质量评估
quality = evaluate_cot_quality(steps)
```

### 4.2 输出格式

```json
{
  "cot_reasoning": {
    "raw_reasoning": "First, I observe the image shows a kitchen with white cabinets...",
    "reasoning_steps": [
      {
        "step_number": 1,
        "marker": "First",
        "content": "I observe the image shows a kitchen..."
      },
      {
        "step_number": 2,
        "marker": "Next",
        "content": "I analyze the layout and features..."
      }
    ],
    "quality_metrics": {
      "logical_flow_score": 0.85,
      "step_count": 4,
      "reasoning_length": 150
    }
  }
}
```

## 5. 完整数据流转

### 5.1 VQA任务完整流程

```
Step 1: 加载图像
image = PIL.Image.open("val2014/000000000139.jpg")

Step 2: 获取问题
question = "What room is shown in the image?"

Step 3: 硬标签生成
hard_label = HardLabelGenerator.generate(image, question)
→ answer="kitchen", confidence=0.92

Step 4: 软标签生成
soft_label = SoftLabelGenerator.generate(image, question)
→ distribution={"kitchen": 0.85, ...}, T=2.0

Step 5: CoT生成
cot = CoTGenerator.generate(image, question)
→ reasoning="First, I observe...", steps=4

Step 6: 合并输出
{
  "tasks": {
    "vqa": {
      "hard_label": {...},
      "soft_label": {...},
      "cot_reasoning": {...}
    }
  }
}
```
