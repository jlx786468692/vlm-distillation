## 第5章 硬标签生成器 (HardLabelGenerator)

> 本章深入讲解硬标签生成的完整实现细节。

### 5.1 模块职责与设计理念

#### 5.1.1 核心职责

```
硬标签生成器的职责:
1. 获取教师模型的最终预测
2. 提取任务特定的结果（答案、标题、检测框）
3. 计算置信度分数
4. 应用置信度阈值过滤
5. 格式化为标准JSON结构
```

#### 5.1.2 设计决策

**决策1: 为什么需要置信度阈值？**

```
场景分析:
- 教师模型可能对某些图像不确定
- 低置信度预测可能包含错误
- 学生模型不应学习不确定的答案

解决方案:
- 设置 confidence_threshold = 0.7
- 低置信度结果标记为 'filtered': True
- 保留原始结果但标记过滤状态

优势:
- 保证训练数据质量
- 可追溯：保留被过滤的数据供分析
- 灵活：用户可调整阈值
```

**决策2: 为什么保存full_response？**

```
full_response: 教师模型的完整生成文本

保存原因:
1. 可追溯：能看到模型的完整输出
2. 调试：便于分析提取逻辑是否正确
3. 扩展：未来可能需要从中提取更多信息
4. 验证：对比提取结果与原始输出

示例:
full_response: "First, I observe... The answer is: kitchen"
extracted_answer: "kitchen"
confidence: 0.92
```

```python
# src/distillation/hard_label_gen.py

def generate_vqa_hard_labels(self, 
                              image_path: str,
                              question: str,
                              image_id: Optional[str] = None) -> Dict[str, Any]:
    """生成VQA硬标签的完整流程"""
    
    # Step 1: 调用教师模型推理
    # 关键点：return_logits=False（不需要logits），generate_cot=False（不需要CoT）
    result = self.teacher.inference_vqa(
        image=image_path,
        question=question,
        return_logits=False,     # 只需要答案，不需要概率分布
        generate_cot=False       # 只需要答案，不需要推理过程
    )
    
    # result 结构:
    # {
    #     'full_response': "Looking at the image... The answer is: kitchen",
    #     'answer': "kitchen",
    #     'confidence': 0.92  # 如果有logits才会计算
    # }
    
    # Step 2: 构建硬标签字典
    hard_label = {
        'image_id': image_id,                     # 图像标识
        'task': 'vqa',                            # 任务类型
        'question': question,                     # 原始问题
        'answer': result.get('answer', ''),       # 提取的答案
        'confidence': result.get('confidence', 0.0),  # 置信度
        'full_response': result.get('full_response', ''),  # 完整输出
        'timestamp': datetime.now().isoformat(),  # 时间戳
    }
    
    # Step 3: 应用置信度过滤
    # 关键点：标记但保留，而不是删除
    if hard_label['confidence'] < self.confidence_threshold:
        hard_label['filtered'] = True
        self.logger.debug(
            f"VQA filtered: confidence {hard_label['confidence']} < "
            f"threshold {self.confidence_threshold}"
        )
    
    # Step 4: 返回结果
    return hard_label
```

## 第6章 软标签生成器 (SoftLabelGenerator)

> 本章深入讲解软标签生成和温度缩放的实现细节。

### 6.1 模块职责与设计理念

#### 6.1.1 核心职责

```
软标签生成器的职责:
1. 获取教师模型的logits输出
2. 应用温度缩放软化概率分布
3. 提取top-k概率（存储优化）
4. 构建概率分布字典
5. 序列化为JSON格式
```

#### 6.1.2 为什么需要top-k？

```
问题:
- 模型词汇表可能有50000+个token
- 存储完整概率分布需要50000个浮点数
- 一张图可能有多个分布（caption的每个位置）
- 存储空间爆炸！

解决方案: top-k保留
- 只保留概率最高的k个token（k=100）
- 存储减少：50000 → 100，减少500倍
- 信息保留：top-100已覆盖99%+的信息

示例:
原始分布: 50000个token的概率
top-k分布: 100个token的概率 + 累积概率
```

```python
def generate_vqa_soft_labels(self,

                              question: str,
                              image_id: Optional[str] = None,
                              answer_candidates: Optional[List[str]] = None) -> Dict[str, Any]:

    )
    
    # result 结构:
    # {
    #     'full_response': "...",
    #     'answer': "kitchen",
    #     'logits': {
    #         'raw_logits': Tensor([seq_len, vocab_size]),
    #         'probabilities': Tensor([seq_len, vocab_size])
    #     },
    #     'confidence': 0.92
    # }
    
    # Step 2: 构建软标签结构
    soft_label = {
        'image_id': image_id,
        'task': 'vqa',
        'question': question,
        'temperature': self.temperature,         # 2.0
        'timestamp': datetime.now().isoformat(),
    }
    
    # Step 3: 处理logits为概率分布
    if 'logits' in result:
        logits_data = result['logits']
        distribution = self._process_vqa_logits(
            logits_data, 
            answer_candidates
        )
        soft_label['answer_distribution'] = distribution
    
    # Step 4: 添加主要答案参考
    soft_label['primary_answer'] = result.get('answer', '')
    soft_label['confidence'] = result.get('confidence', 0.0)
    
    return soft_label
```

#### 6.2.2 logits处理流程

```python
def _process_vqa_logits(self,
                         logits_data: Dict[str, torch.Tensor],
                         answer_candidates: Optional[List[str]] = None) -> Dict[str, float]:
    """处理logits为答案概率分布"""
    
    probs = logits_data.get('probabilities')
    if probs is None:
        return {}
    
    # Step 1: 应用温度缩放
    scaled_probs = self._apply_temperature(probs)
    
    # Step 2: 提取top-k概率
    top_k_probs = self._get_top_k_probabilities(scaled_probs)
    
    # Step 3: 构建分布字典
    distribution = {}
    
    if answer_candidates:
        # 如果提供了候选答案
        # 计算每个候选的概率（需要实现候选映射到token的逻辑）
        for i, candidate in enumerate(answer_candidates[:self.top_k]):
            distribution[candidate] = 1.0 / len(answer_candidates[:self.top_k])
    else:
        # 使用top token概率
        for i, prob_val in enumerate(top_k_probs['values'][:self.top_k]):
            if prob_val >= self.min_probability:
                # 注：实际应将token_id映射到文本
                distribution[f'token_{i}'] = float(prob_val)
    
    return distribution
```

### 6.3 温度缩放实现详解

#### 6.3.1 算法实现

```python
def _apply_temperature(self, probs: torch.Tensor) -> torch.Tensor:
    """温度缩放的完整实现"""
    
    # 输入: probs = softmax(logits)
    #       shape: [batch_size, seq_len, vocab_size] 或 [seq_len, vocab_size]
    
    # Step 1: 从概率反推logits
    # 数学原理: logits = log(P)
    # 技巧: 加小常数防止 log(0) = -inf
    logits = torch.log(probs + 1e-10)  # epsilon = 1e-10
    
    # Step 2: 应用温度缩放
    # 数学原理: scaled_logits = logits / T
    scaled_logits = logits / self.temperature
    
    # Step 3: 重新计算softmax
    # 数学原理: scaled_probs = softmax(scaled_logits)
    scaled_probs = torch.softmax(scaled_logits, dim=-1)
    
    return scaled_probs
```

#### 6.3.2 数学推导

```
原始logits: z = [z_1, z_2, ..., z_n]

原始概率: P_i = exp(z_i) / sum(exp(z_j))

反推logits: log(P_i) = z_i - log(sum(exp(z_j)))
           ≈ z_i （当某个概率很大时）

温度缩放: z'_i = z_i / T

缩放概率: P'_i = exp(z_i/T) / sum(exp(z_j/T))

效果分析:
- T=1: P'_i = P_i （无变化）
- T>1: z'_i变小，exp(z'_i)差距缩小，分布更平滑
- T<1: z'_i变大，exp(z'_i)差距增大，分布更尖锐
```

### 6.4 Top-k提取详解

```python
def _get_top_k_probabilities(self, probs: torch.Tensor) -> Dict[str, torch.Tensor]:
    """提取top-k概率"""
    
    # 输入: probs shape = [seq_len, vocab_size]
    
    # Step 1: 如果是多维，展平
    if probs.dim() > 1:
        probs_flat = probs.view(-1)  # [seq_len * vocab_size]
    else:
        probs_flat = probs
    
    # Step 2: 获取top-k
    top_k = min(self.top_k, probs_flat.size(0))  # k=100
    top_values, top_indices = torch.topk(probs_flat, top_k)
    
    # 返回:
    return {
        'indices': top_indices,  # top token的ID
        'values': top_values,    # top token的概率
    }
```

### 6.5 JSON序列化处理

```python
def _make_serializable(self, data: Dict) -> Dict:
    """将Tensor转换为可JSON序列化的格式"""
    
    # 问题: torch.Tensor和numpy.ndarray不能直接JSON序列化
    
    serializable = {}
    
    for key, value in data.items():
        
        # 处理torch.Tensor
        if isinstance(value, torch.Tensor):
            serializable[key] = value.tolist()  # Tensor → List
        
        # 处理numpy.ndarray
        elif isinstance(value, np.ndarray):
            serializable[key] = value.tolist()  # ndarray → List
        
        # 处理嵌套dict
        elif isinstance(value, dict):
            serializable[key] = self._make_serializable(value)  # 递归
        
        # 处理嵌套list
        elif isinstance(value, list):
            serializable[key] = [
                self._make_serializable(v) if isinstance(v, dict) else
                v.tolist() if isinstance(v, (torch.Tensor, np.ndarray)) else v
                for v in value
            ]
        
        # 其他类型直接保存
        else:
            serializable[key] = value
    
    return serializable
```

### 7.3 推理步骤提取详解

```python
def _extract_reasoning_steps(self, raw_reasoning: str) -> List[Dict]:
    """提取推理步骤的详细实现"""
    
    # 示例输入:
    # "First, I identify a person. Next, I see a bicycle. 
    #  Then, I notice motion. Finally, I conclude they are riding."
    
    # Step 1: 定义步骤标记正则表达式
    pattern = r'(Step \d+|First|Next|Then|Finally|Therefore)'
    
    # Step 2: 使用正则表达式分割
    parts = re.split(pattern, raw_reasoning)
    
    # parts 示例:
    # ['', 'First', ', I identify a person. ', 'Next', 
    #  ', I see a bicycle. ', 'Then', ', I notice motion. ', 
    #  'Finally', ', I conclude they are riding.']
    
    # Step 3: 重构步骤列表
    steps = []
    for i in range(1, len(parts), 2):
        if i < len(parts):
            marker = parts[i]        # 'First', 'Next', etc.
            content = parts[i + 1] if i + 1 < len(parts) else ''
            
            steps.append({
                'step_number': len(steps) + 1,
                'marker': marker.strip(),
                'content': content.strip(),
            })
    
    # steps 示例:
    # [
    #   {'step_number': 1, 'marker': 'First', 'content': 'I identify a person'},
    #   {'step_number': 2, 'marker': 'Next', 'content': 'I see a bicycle'},
    #   {'step_number': 3, 'marker': 'Then', 'content': 'I notice motion'},
    #   {'step_number': 4, 'marker': 'Finally', 'content': 'I conclude they are riding'}
    # ]
    
    # Step 4: 如果未识别到标记，按句子分割
    if not steps:
        sentences = raw_reasoning.split('.')
        for i, sentence in enumerate(sentences[:5]):  # 最多5步
            if sentence.strip():
                steps.append({
                    'step_number': i + 1,
                    'marker': '',
                    'content': sentence.strip(),
                })
    
    return steps
```

### 7.4 质量评估详解

```python
def _validate_reasoning_quality(self, reasoning: str) -> Dict:
    """评估推理链质量"""
    
    metrics = {
        'length': len(reasoning),
        'has_required_keywords': False,
        'keyword_count': 0,
        'step_count': 0,
        'logical_flow_score': 0.0,
        'is_valid': False,
    }
    
    # 必需关键词（推理标记）
    required_keywords = [
        'first', 'next', 'then', 'finally',
        'therefore', 'because', 'so'
    ]
    
    # Step 1: 计算关键词数量
    keyword_count = sum(1 for kw in required_keywords 
                        if kw in reasoning.lower())
    metrics['keyword_count'] = keyword_count
    metrics['has_required_keywords'] = keyword_count >= 2
    
    # Step 2: 估计步骤数
    steps = self._extract_reasoning_steps(reasoning)
    metrics['step_count'] = len(steps)
    
    # Step 3: 计算逻辑流畅度
    # 流畅度 = keyword_count / 5.0 (最多5个关键词)
    if metrics['has_required_keywords'] and metrics['step_count'] >= 2:
        metrics['logical_flow_score'] = min(keyword_count / 5.0, 1.0)
    
    # Step 4: 判断有效性
    # 有效条件:
    # - 长度 >= 30字符（足够详细）
    # - 关键词 >= 2个（有推理标记）
    # - 步骤 >= 2个（有推理过程）
    metrics['is_valid'] = (
        metrics['length'] >= 30 and
        metrics['has_required_keywords'] and
        metrics['step_count'] >= 2
    )
    
    return metrics
```

```python
def save_result(self, result: Dict[str, Any], 
                output_path: str, 
                validate: bool = True) -> bool:
    """保存单个结果"""
    
    # Step 1: 验证结果结构（可选）
    if validate:
        if not self._validate_result(result):
            self.logger.warning(f"Invalid result, skipping save to {output_path}")
            return False
    
    # Step 2: 添加时间戳（如果缺失）
    if 'timestamp' not in result:
        result['timestamp'] = datetime.now().isoformat()
    
    # Step 3: 创建目录（如果不存在）
    path = Path(output_path)
    path.parent.mkdir(parents=True, exist_ok=True)
    
    # Step 4: 写入JSON文件
    try:
        with open(path, 'w', encoding='utf-8') as f:
            json.dump(result, f, indent=2, ensure_ascii=False)
        
        self.logger.debug(f"Result saved to {path}")
        return True
    
    except Exception as e:
        self.logger.error(f"Failed to save result: {e}")
        return False
```

### 8.3 结果合并详解

```python
def merge_all_results(self, batch_files: Optional[List[str]] = None) -> Dict[str, Any]:
    """合并所有批处理结果"""
    
    # Step 1: 查找所有batch文件
    if batch_files is None:
        batch_pattern = str(self.output_dir / "batch_*.json")
        batch_files = glob.glob(batch_pattern)
    
    if not batch_files:
        self.logger.warning("No batch files found")
        return {'status': 'no_files', 'merged_count': 0}
    
    # Step 2: 加载所有批结果
    all_results = []
    
    for batch_file in batch_files:
        try:
            with open(batch_file, 'r') as f:
                batch_data = json.load(f)
            
            # 提取图像结果
            if 'images' in batch_data:
                all_results.extend(batch_data['images'])
        
        except Exception as e:
            self.logger.error(f"Failed to load {batch_file}: {e}")
    
    # Step 3: 按image_id合并
    merged_by_image = {}
    
    for img_result in all_results:
        image_id = img_result.get('image_id')
        
        if image_id in merged_by_image:
            # 合相同image_id的tasks
            for task, task_data in img_result.get('tasks', {}).items():
                if task in merged_by_image[image_id]['tasks']:
                    merged_by_image[image_id]['tasks'][task].update(task_data)
                else:
                    merged_by_image[image_id]['tasks'][task] = task_data
        else:
            merged_by_image[image_id] = img_result
    
    # Step 4: 保存合并结果
    merged_count = 0
    
    for image_id, merged_data in merged_by_image.items():
        merged_file = self.output_dir / "merged" / f"{image_id}.json"
        
        if self.save_result(merged_data, str(merged_file), validate=False):
            merged_count += 1
    
    # Step 5: 创建合并摘要
    summary_file = self.output_dir / "merged_summary.json"
    summary = {
        'total_images': merged_count,
        'batch_files_processed': len(batch_files),
        'tasks': self.config.get("distillation.tasks"),
        'merge_timestamp': datetime.now().isoformat(),
    }
    
    with open(summary_file, 'w') as f:
        json.dump(summary, f, indent=2)
    
    # Step 6: 归档批文件
    if merged_count > 0:
        self._cleanup_batch_files(batch_files)
    
    return {
        'status': 'success',
        'merged_count': merged_count,
        'summary_path': str(summary_file),
    }
```

### 8.4 批文件归档

```python
def _cleanup_batch_files(self, batch_files: List[str]) -> None:
    """归档批处理文件"""
    
    # Step 1: 创建归档目录
    archive_dir = self.output_dir / "archive"
    archive_dir.mkdir(exist_ok=True)
    
    # Step 2: 生成时间戳
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    
    # Step 3: 移动批文件
    for batch_file in batch_files:
        try:
            batch_path = Path(batch_file)
            archived_path = archive_dir / f"{batch_path.stem}_{timestamp}.json"
            shutil.move(batch_file, str(archived_path))
        
        except Exception as e:
            self.logger.warning(f"Failed to archive {batch_file}: {e}")
    
    self.logger.info(f"Archived {len(batch_files)} batch files")
```

```python
torch_dtype = torch.float32
内存占用: 7B参数 × 4字节 = 28GB
特点: 最高精度，但内存最大

# FP16 (半精度)
torch_dtype = torch.float16
内存占用: 7B参数 × 2字节 = 14GB
特点: 内存减半，但可能有精度损失

# BF16 (Brain Float16) - 推荐
torch_dtype = torch.bfloat16
内存占用: 7B参数 × 2字节 = 14GB
特点: 
- 内存与FP16相同
- 动态范围更大（避免溢出）
- A100/V100/RTX 3090+支持
- 训练更稳定

# 使用方式
config.set('teacher.precision', 'bf16')
```
