## 5. 数据质量校验模块 (src/utils/)

### 5.1 DataQualityValidator

完整的VLM蒸馏数据质量校验系统，详见 [数据质量校验系统详解.md](数据质量校验系统详解.md)

```python
from src.utils import DataQualityValidator

validator = DataQualityValidator(config, logger)

# 运行完整校验
# 报告自动保存到 ./outputs/data_quality_validation_report.json
report = validator.run_full_validation(
    input_dir='./outputs/cleaned/cleaned'
)

# 输出
{
    'success': True,
    'overall_passed': True,
    'sample_count': 100,
    'validation_results': {
        'soft_label_distribution': {...},
        'ece_calibration': {...},
        'top_k_matching': {...},
        'cot_quality': {...},
        'training_value_assessment': {...}
    }
}
```

**校验指标体系**:

| 指标 | 说明 | 阈值 | 方法 |
|------|------|------|------|
| Top-K匹配率 | 教师预测准确性 | ≥ 88% | `_validate_top_k_matching()` |
| KL散度 | 预测失真程度 | < 0.5 | `_compute_kl_divergence()` |
| ECE校准误差 | 置信度可靠性 | < 0.15 | `_validate_ece_calibration()` |
| 幻觉占比 | CoT真实性 | < 5% | `_detect_hallucinations()` |
| 分布相关性 | 类别分布对齐 | > 0.8 | `_check_category_distribution_alignment()` |

**数据阶段判定**:

满足以下全部才具备训练价值：
- ✅ Top1匹配率 ≥ 88%
- ✅ 平均KL散度 < 0.5
- ✅ CoT幻觉占比 < 5%
- ✅ 类别分布相关性 > 0.8
