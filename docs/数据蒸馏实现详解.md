## 3. 三种标签生成

### 3.1 硬标签 (Hard Label)

```python
from src.distillation import HardLabelGenerator

gen = HardLabelGenerator(teacher, config)
result = gen.generate_vqa(image, question)

# 输出格式
{
    "question": "What is in the image?",
    "answer": "kitchen",
    "confidence": 0.92,
    "full_response": "The image shows..."
}
```

### 3.2 软标签 (Soft Label)

```python
from src.distillation import SoftLabelGenerator

gen = SoftLabelGenerator(teacher, config)
result = gen.generate_vqa(image, question)

# 输出格式
{
    "answer_distribution": {
        "kitchen": 0.92,
        "bedroom": 0.05,
        "bathroom": 0.03
    },
    "temperature": 2.0,
    "top_k_logits": 100
}
```

**温度缩放原理**:

```
原始分布: P(y) = softmax(logits)
温度分布: P_T(y) = softmax(logits / T)

T=1:  [0.95, 0.03, 0.02]  ← 过于尖锐
T=2:  [0.85, 0.10, 0.05]  ← 平滑合理 ✅
T=5:  [0.60, 0.25, 0.15]  ← 过于平滑
```

### 3.3 思维链 (CoT)

```python
from src.distillation import CoTGenerator

gen = CoTGenerator(teacher, config)
result = gen.generate_vqa(image, question)

# 输出格式
{
    "raw_reasoning": "First, I observe the image shows...",
    "reasoning_steps": [
        {"step_number": 1, "content": "I observe..."},
        {"step_number": 2, "content": "I analyze..."}
    ],
    "quality_metrics": {
        "logical_flow_score": 0.8,
        "step_count": 4
    }
}
```

## 4. 数据清洗流程

### 4.1 异常检测 (7种类型)

| 异常类型 | 检测条件 |
|----------|----------|
| low_confidence | confidence < 0.5 |
| invalid_answers | 'unknown', 'N/A', 空 |
| empty_results | 无caption/检测结果 |
| bbox_anomalies | bbox超出范围 |
| cot_low_quality | logical_flow < 0.5 |
| length_anomalies | 长度异常 |
| format_errors | 格式错误 |

### 4.2 质量评分

```
质量分数计算:
1. 硬标签质量 (0-40分):
   - 置信度: ≥0.7→30分, ≥0.5→20分, ≥0.3→10分
   - 答案长度: 3-100字符→10分

2. 软标签质量 (0-20分):
   - 温度: 1.5-3.0→10分
   - 分布完整→10分

3. CoT质量 (0-30分):
   - 逻辑流畅度: score × 15
   - 步骤数: 3-5步→15分

最终分数: min(avg_score, 100)
```
