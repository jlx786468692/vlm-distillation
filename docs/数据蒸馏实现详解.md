# VLM 数据蒸馏实现详解

## 1. 整体架构

数据蒸馏流程采用"教师-学生"模式，使用大型视觉语言模型（Qwen2.5-VL-7B-Instruct）作为教师模型，为后续的学生模型训练生成高质量的训练数据。

### 核心组件关系图

```
┌─────────────────────────────────────────────────────────────┐
│                     数据蒸馏流程                              │
└─────────────────────────────────────────────────────────────┘

输入数据 → 数据管理器 → 蒸馏器 → 三种标签生成器 → 输出合并器 → 清洗器
   │           │          │            │              │          │
   │           │          │            │              │          │
COCO数据集   采样策略   协调控制     硬/软/CoT      JSON导出   质量控制
   │           │          │            │              │          │
   │           │          │            │              │          │
5000张图像   批次管理   任务分配     标签生成       文件保存   异常检测
                        │            │              │          │
                        │            │              │          │
                    ┌───┴────────────┴───┐      ┌──┴──────────┴──┐
                    │  教师模型接口      │      │  数据清洗器     │
                    │  (TeacherModel)   │      │ (DataCleaner)  │
                    └────────────────────┘      └─────────────────┘
```

- 管理检查点恢复

### Step 2: 主蒸馏协调器 (`Distiller`)

**文件位置**: `src/distillation/distiller.py`

**主要职责**:
- 协调整个蒸馏流程
- 分配任务到不同的生成器
- 管理批次处理进度
- 保存检查点和最终结果

**核心流程**:

```python
def run_distillation(max_samples=4):
    # 1. 获取样本ID
    sample_ids = data_manager.get_sample_ids()[:max_samples]

    # 2. 创建批次
    batches = data_manager.create_batches(sample_ids)
    # 每批次包含batch_size张图像（默认4张）

    # 3. 处理每个批次
    for batch_idx, batch_ids in enumerate(batches):
        # 获取批次数据（图像路径、标注）
        batch_data = data_manager.get_batch_data(batch_ids)

        # 处理批次（生成三种标签）
        batch_results = process_batch(batch_data)

        # 保存批次结果到JSON
        _save_batch_results(batch_results, batch_idx)

        # 定期保存检查点
        if processed_count % checkpoint_interval == 0:
            _save_checkpoint(processed_ids)

    # 4. 合并所有批次结果
    merged_results = exporter.merge_all_results()
```

**单批次处理逻辑**:

```python
def process_batch(batch_data):
    batch_results = {'images': []}

    for img_data in batch_data['images']:
        image_id = img_data['id']
        image_path = img_data['path']

        # 为每个任务生成三种标签
        image_result = {
            'image_id': image_id,
            'tasks': {}
        }

        for task in ['vqa', 'captioning', 'detection']:
            # 硬标签（最终预测）
            hard_labels = hard_label_gen.generate_task_hard_labels(task, ...)

            # 软标签（概率分布）
            soft_labels = soft_label_gen.generate_task_soft_labels(task, ...)

            # 思维链推理（CoT）
            cot = cot_gen.generate_task_cot(task, ...)

            image_result['tasks'][task] = {
                'hard_label': hard_labels,
                'soft_label': soft_labels,
                'cot_reasoning': cot
            }

        batch_results['images'].append(image_result)

    return batch_results
```

### Step 3: 教师模型接口 (`TeacherModel`)

**文件位置**: `src/models/teacher_model.py`

**主要职责**:
- 加载和管理Qwen2.5-VL-7B-Instruct模型
- 提供多任务推理接口（VQA/图像描述/目标检测）
- 支持返回logits用于软标签生成
- 支持生成CoT推理链

**模型加载**:

```python
def _load_model():
    # 1. 加载processor（图像处理器）
    processor = AutoProcessor.from_pretrained("Qwen/Qwen2.5-VL-7B-Instruct")

    # 2. 加载tokenizer（文本分词器）
    tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen2.5-VL-7B-Instruct")

    # 3. 加载视觉语言模型
    model = AutoModelForVision2Seq.from_pretrained(
        "Qwen/Qwen2.5-VL-7B-Instruct",
        torch_dtype=torch.bfloat16,  # bf16精度节省显存
        device_map='cuda',           # GPU加速
        trust_remote_code=True
    )
```

**三大推理接口**:

```python
# 1. VQA推理
def inference_vqa(image, question, return_logits=False, generate_cot=False):
    # 构建prompt
    if generate_cot:
        prompt = "Let's think step by step to answer this question..."
    else:
        prompt = f"Question: {question}\nAnswer:"

    # 准备输入（图像+文本）
    inputs = processor(image, prompt, return_tensors="pt")

    # 模型生成
    outputs = model.generate(
        inputs,
        max_new_tokens=512,
        temperature=0.7,
        top_p=0.9
    )

    # 返回答案、置信度、logits（可选）、CoT（可选）
    return {
        'answer': 'blue',           # 硬标签答案
        'confidence': 0.85,         # 置信度
        'logits': tensor([...]),    # 软标签原始概率
        'full_response': '...'      # CoT完整推理
    }

# 2. 图像描述推理
def inference_captioning(image, num_captions=3, return_logits=False, generate_cot=False):
    prompt = "Describe this image in detail."

    # 生成多个caption（增加多样性）
    captions = []
    for i in range(num_captions):
        output = model.generate(inputs, temperature=0.7+i*0.1)
        captions.append(processor.decode(output))

    return {
        'captions': [
            "A blue car parked on the street...",
            "The image shows a vehicle...",
            "There is a automobile..."
        ],
        'logits': [...],  # 每个caption的概率分布
        'cot': "First, I observe the main object..."
    }

# 3. 目标检测推理
def inference_detection(image, return_logits=False, generate_cot=False):
    prompt = "Detect all objects in this image and provide their bounding boxes."

    outputs = model.generate(inputs)

    # 解析检测结果
    objects = parse_detection_output(outputs)
    # 格式：[
    #   {'class': 'car', 'bbox': [x_min, y_min, x_max, y_max], 'confidence': 0.92},
    #   {'class': 'person', 'bbox': [...], 'confidence': 0.88}
    # ]

    return {
        'objects': objects,
        'num_objects': len(objects),
        'cot': "I first scan the image for large objects..."
    }
```

## 3. 三种标签类型详解

### 3.1 硬标签 (Hard Labels)

**生成器**: `src/distillation/hard_label_gen.py`

**定义**: 教师模型的最终预测结果，包含明确的答案和置信度分数

**生成逻辑**:

```python
# VQA硬标签
def generate_vqa_hard_labels(image_path, question):
    result = teacher.inference_vqa(
        image=image_path,
        question=question,
        return_logits=False,    # 不需要概率分布
        generate_cot=False      # 不需要推理过程
    )

    hard_label = {
        'task': 'vqa',
        'question': question,
        'answer': result['answer'],         # "blue"
        'confidence': result['confidence'], # 0.85
        'timestamp': datetime.now()
    }

    # 置信度过滤（可选）
    if hard_label['confidence'] < 0.7:
        hard_label['filtered'] = True  # 标记为低置信度

    return hard_label

# 图像描述硬标签
def generate_captioning_hard_labels(image_path, num_captions=3):
    result = teacher.inference_captioning(
        image=image_path,
        num_captions=num_captions
    )

    hard_label = {
        'task': 'captioning',
        'captions': result['captions'],  # ["A blue car...", "The image shows..."]
        'num_captions': len(result['captions']),
        'primary_caption': result['captions'][0],  # 主描述
        'caption_scores': [1.0, 0.95, 0.90]  # 每个caption的质量分数
    }

    return hard_label

# 目标检测硬标签
def generate_detection_hard_labels(image_path):
    result = teacher.inference_detection(image_path)

    # 置信度过滤
    filtered_objects = [
        obj for obj in result['objects']
        if obj['confidence'] >= confidence_threshold  # 默认0.7
    ]

    hard_label = {
        'task': 'detection',
        'objects': filtered_objects,
        'num_objects': len(filtered_objects),
        # 示例:
        # objects: [
        #   {'class': 'car', 'bbox': [100, 200, 300, 400], 'confidence': 0.92},
        #   {'class': 'person', 'bbox': [50, 80, 120, 200], 'confidence': 0.88}
        # ]
    }

    return hard_label
```

### 3.2 软标签 (Soft Labels)

**生成器**: `src/distillation/soft_label_gen.py`

**定义**: 教师模型输出的概率分布，提供更丰富的信息用于知识蒸馏

**核心概念**:
- **Temperature Scaling**: 使用温度参数平滑概率分布
- **Top-k Probabilities**: 只保留top-k个最高概率，节省存储空间
- **Knowledge Distillation**: 学生模型学习教师模型的"思考过程"（概率分布）

**生成逻辑**:

```python
def generate_vqa_soft_labels(image_path, question):
    # 获取带logits的推理结果
    result = teacher.inference_vqa(
        image=image_path,
        question=question,
        return_logits=True,    # 返回原始logits
        generate_cot=False
    )

    # 提取logits并转换为概率分布
    logits = result['logits']  # shape: [vocab_size]

    # Temperature scaling
    temperature = 2.0  # 配置参数
    scaled_logits = logits / temperature

    # 转换为概率
    probabilities = torch.softmax(scaled_logits, dim=-1)

    # 只保留top-k高概率token（节省存储）
    top_k = 100
    top_probs, top_indices = torch.topk(probabilities, k=top_k)

    soft_label = {
        'task': 'vqa',
        'temperature': temperature,
        'answer_distribution': {
            'tokens': top_indices.tolist(),      # Token IDs
            'probabilities': top_probs.tolist(), # 对应概率
            # 示例:
            # tokens: [1234, 5678, 9012, ...]  # "blue", "red", "green", ...
            # probabilities: [0.45, 0.25, 0.15, ...]
        },
        'primary_answer': result['answer'],  # 用于参考
        'confidence': result['confidence']
    }

    return soft_label
```

**软标签的作用**:

```python
# 传统硬标签训练（学生模型只学习最终答案）
student_output = student_model(image, question)
loss = CrossEntropy(student_output, "blue")  # 只看正确答案

# 软标签知识蒸馏（学生模型学习教师的"不确定性"）
teacher_probs = [0.45, 0.25, 0.15, 0.10, 0.05]  # 教师: 45%蓝色, 25%红色...
student_probs = student_model(image, question)

# KL散度损失（学习整个分布）
loss = KL_Divergence(student_probs, teacher_probs)
# 学生不仅学会"答案是蓝色"，还学会"可能是红色或绿色"
```

**优势**:
- 提供更丰富的信息（不仅是答案，还有"思考过程"）
- 帮助学生模型学习教师模型的不确定性
- 提升学生模型的泛化能力

### 3.3 思维链推理 (Chain-of-Thought, CoT)

**生成器**: `src/distillation/cot_generator.py`

**定义**: 教师模型的逐步推理过程，展示如何得出答案

**核心概念**:
- **Structured Reasoning**: 将推理过程分解为结构化步骤
- **Intermediate Steps**: 提取关键推理步骤
- **Quality Validation**: 验证推理链的逻辑质量

**生成逻辑**:

```python
def generate_vqa_cot(image_path, question):
    # 构建CoT prompt
    cot_prompt = f"""
    Let's think step by step to answer this question.

    Question: {question}

    First, let me observe the image carefully.
    Next, I'll identify the relevant objects.
    Then, I'll analyze their attributes.
    Finally, I'll conclude with the answer.

    Step-by-step reasoning:
    """

    # 获取CoT推理
    result = teacher.inference_vqa(
        image=image_path,
        question=cot_prompt,    # 使用CoT prompt
        return_logits=False,
        generate_cot=True
    )

    full_response = result['full_response']
    # 示例输出:
    # "First, I observe a car in the center of the image.
    #  Next, I notice the color appears to be a shade of blue.
    #  Then, I check if there are any reflections that might change the color perception.
    #  The lighting seems natural, so the color is accurate.
    #  Therefore, the car is blue."

    # 结构化推理
    cot_data = {
        'task': 'vqa',
        'question': question,
        'raw_reasoning': full_response,
        'structured_reasoning': _structure_vqa_reasoning(full_response),
        'reasoning_steps': _extract_reasoning_steps(full_response),
        'quality_metrics': _validate_reasoning_quality(full_response)
    }

    return cot_data

# 提取推理步骤
def _extract_reasoning_steps(full_response):
    # 按关键词分割步骤
    keywords = ['first', 'next', 'then', 'finally', 'therefore']

    steps = []
    for keyword in keywords:
        if keyword in full_response.lower():
            # 提取该步骤的内容
            step_content = extract_step_by_keyword(full_response, keyword)
            steps.append({
                'step_number': len(steps) + 1,
                'keyword': keyword,
                'content': step_content
            })

    # 示例输出:
    # steps: [
    #   {'step_number': 1, 'keyword': 'first', 'content': 'I observe a car...'},
    #   {'step_number': 2, 'keyword': 'next', 'content': 'I notice the color...'},
    #   {'step_number': 3, 'keyword': 'then', 'content': 'I check reflections...'},
    #   {'step_number': 4, 'keyword': 'finally', 'content': 'The lighting...'},
    #   {'step_number': 5, 'keyword': 'therefore', 'content': 'The car is blue'}
    # ]

    return steps

# 验证推理质量
def _validate_reasoning_quality(full_response):
    metrics = {
        'step_count': count_reasoning_steps(full_response),
        'logical_flow_score': evaluate_logical_flow(full_response),
        'reasoning_length': len(full_response),
        'has_keywords': check_required_keywords(full_response),
        'coherence_score': evaluate_coherence(full_response)
    }

    # 示例输出:
    # metrics: {
    #   'step_count': 5,
    #   'logical_flow_score': 0.85,  # 逻辑流畅度（0-1）
    #   'reasoning_length': 245,
    #   'has_keywords': True,
    #   'coherence_score': 0.90
    # }

    return metrics
```

**CoT的作用**:


## 7. 数据清洗流程

### 为什么需要清洗？

蒸馏生成的数据可能存在质量问题：
- 低置信度预测（模型不确定）
- 空结果（某些任务失败）
- 格式错误（解析失败）
- 长度异常（过短或过长）
- CoT质量低（推理逻辑混乱）

### 清洗步骤 (`src/cleaning/data_cleaner.py`)

```python
def clean_directory(input_dir, output_dir):
    # Step 1: 加载所有蒸馏数据
    all_data = load_all_json_files(input_dir)

    # Step 2: 异常检测（多维度）
    anomalies = {
        'low_confidence': [],      # 置信度 < 0.5
        'empty_results': [],       # caption或detection为空
        'invalid_answers': [],     # 答案为"unknown", "n/a"等
        'bbox_anomalies': [],      # 检测框超出范围或尺寸异常
        'cot_low_quality': [],     # CoT逻辑流畅度 < 0.5
        'length_anomalies': [],    # 答案长度 < 3 或 > 100
        'format_errors': []        # JSON格式错误
    }

    # Step 3: 质量评分（0-100）
    quality_scores = compute_quality_scores(all_data)
    # 评分维度：
    # - 硬标签质量 (0-40分): 置信度、答案完整性
    # - 软标签质量 (0-20分): 温度参数、分布完整性
    # - CoT质量 (0-30分): 逻辑流畅度、步骤数量
    # - 加分项 (0-10分): 多样性、完整性

    # Step 4: 应用清洗规则
    for data in all_data:
        should_remove = False

        # 规则1: 质量分数过低
        if quality_score < 30.0:
            should_remove = True

        # 规则2: 无效答案
        if answer in ['unknown', 'n/a', 'none']:
            should_remove = True

        # 规则3: 空结果（修复后可配置）
        if has_empty_caption or has_empty_detection:
            if remove_empty_results:  # 新增配置项
                should_remove = True

        # 规则4: 格式错误
        if bbox_format_invalid:
            should_remove = True

        # 规则5: 多个低置信度（≥2个任务低置信度）
        if low_confidence_count >= 2:
            should_remove = True

        # 规则6: CoT严重质量问题
        if cot_quality_score < 0.3:
            should_remove = True

        if should_remove:
            removed_data.append(data)
        else:
            cleaned_data.append(data)

    # Step 5: 数据去重
    deduplicated_data = deduplicate_by_answer_similarity(cleaned_data)

    # Step 6: 数据修复（可选）
    repaired_data = repair_bbox_anomalies(deduplicated_data)

    # Step 7: 保存结果
    save_cleaned_data(repaired_data, 'outputs/cleaned/cleaned/')
    save_removed_data(removed_data, 'outputs/cleaned/removed/')
    save_cleaning_report('outputs/cleaned/cleaning_report.json')
```

## 总结

数据蒸馏是一个完整的流程，从数据加载到清洗输出，每一步都有明确的职责：

1. **DataManager**: 数据采样与批次管理
2. **Distiller**: 流程协调与任务分配
3. **TeacherModel**: 大型VLM推理接口
4. **生成器**: 硬标签、软标签、CoT三种标签生成
5. **DataCleaner**: 质量控制与异常检测

最终目标：生成高质量的训练数据，用于训练更小、更高效的学生模型，实现模型压缩和性能保留。
