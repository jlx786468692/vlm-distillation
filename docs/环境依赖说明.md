## 安装指南

### 方式1：使用 Conda（推荐）

```bash
# 创建环境
conda create -n vlm-env python=3.10 -y
conda activate vlm-env

# 安装 PyTorch (CUDA 12.4)
conda install pytorch torchvision torchaudio pytorch-cuda=12.4 -c pytorch -c nvidia -y

# 安装核心依赖
pip install transformers>=4.49.0 accelerate>=1.14.0
pip install numpy scipy pillow tqdm pyyaml requests opencv-python

# 安装 vLLM（推荐，用于 AWQ 模型）
pip install vllm>=0.6.0
```

### 方式2：使用 pip

```bash
# 创建环境
conda create -n vlm-env python=3.10 -y
conda activate vlm-env

# 安装 PyTorch (CUDA 12.4)
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124

# 安装其他依赖
pip install -r requirements.txt
```

### requirements.txt 内容

## 版本选择理由

### 1. Python 3.10.20

**选择理由**：
- ✅ 稳定性：Python 3.10 是目前最稳定的 LTS 版本
- ✅ 兼容性：PyTorch、vLLM、transformers 都完全支持
- ✅ 类型提示：支持现代 Python 特性（类型注解、match-case 等）
- ⚠️ 注意：Python 3.11+ 可能有部分库兼容性问题

**为什么不选 3.11/3.12**：
- vLLM 部分版本不支持 Python 3.11+
- 某些 C 扩展编译可能失败

---

### 2. PyTorch 2.5.1 + CUDA 12.4

**选择理由**：
- ✅ **CUDA 12.4 兼容性**：
  - 系统 CUDA Driver 是 12.9
  - PyTorch CUDA 12.4 是官方最新稳定版本
  - 向前兼容（12.4 编译的代码可在 12.9 driver 上运行）
  
- ✅ **性能优化**：
  - PyTorch 2.5 包含 `torch.compile` 优化
  - 更好的 CUDA kernel 优化
  - 支持 Flash Attention 2

- ✅ **AWQ 支持**：
  - transformers 4.37+ 支持原生 AWQ 加载
  - vLLM 对 PyTorch 2.5 支持完善

**为什么不选 2.6+**：
- PyTorch 2.6+ 尚未发布稳定版
- vLLM 可能兼容性未验证

---

### 3. transformers 4.49.0

**选择理由**：
- ✅ **Qwen2.5-VL 支持**：
  - 原生支持 `Qwen2_5_VLForConditionalGeneration`
  - 完整的 processor 和 tokenizer
  
- ✅ **AWQ 支持**：
  - 原生加载 AWQ 量化模型（配合 autoawq）
  - 无需额外量化配置

- ✅ **最新特性**：
  - 支持 trust_remote_code
  - 改进的图像处理 pipeline

**最低版本要求**：
- `transformers>=4.37.0`：AWQ 原生支持
- `transformers>=4.45.0`：Qwen2.5-VL 支持

---

### 4. vLLM ≥0.6.0（推荐）

**选择理由**：
- ✅ **原生 AWQ 支持**：
  - 无需 autoawq/gptqmodel
  - 直接加载 AWQ 量化模型
  
- ✅ **性能优势**：
  - 推理速度比 transformers 快 2-4x
  - PagedAttention 优化显存
  - Continuous batching 提高吞吐量

- ✅ **多卡并行**：
  - 原生支持 tensor parallel
  - 自动负载均衡

- ✅ **显存效率**：
  - KV cache 优化
  - 支持 GPU 显存动态分配

**为什么不用 transformers + autoawq**：
| 对比项 | vLLM | transformers + autoawq |
|--------|------|------------------------|
| 依赖 | 仅 vLLM | transformers + autoawq |
| 速度 | 最快 | 基准 |
| 显存 | 最优 | 标准 |
| 多卡 | 原生 | 需配置 |

---

### 5. accelerate 1.14.0

**选择理由**：
- ✅ **模型加载优化**：
  - `device_map="auto"` 自动分配设备
  - 支持模型分片加载
  
- ✅ **显存优化**：
  - 支持 offload 到 CPU
  - 动态显存管理

- ✅ **分布式推理**：
  - 简化多卡推理代码
  - 自动处理设备间通信

---

### 6. CUDA 版本选择

| CUDA 版本 | PyTorch 版本 | 兼容性 | 推荐 |
|-----------|-------------|--------|------|
| CUDA 11.8 | PyTorch 2.0-2.4 | 稳定 | ⚠️ 较旧 |
| CUDA 12.1 | PyTorch 2.2-2.5 | 稳定 | ✅ 推荐 |
| CUDA 12.4 | PyTorch 2.5+ | 最新 | ✅ **最推荐** |

**为什么选 CUDA 12.4**：
- ✅ 系统 Driver 是 CUDA 12.9，向前兼容
- ✅ PyTorch 官方最新稳定版
- ✅ vLLM 完整支持
- ✅ 性能最优

## 常见问题

### Q1: 为什么不用 gptqmodel？

**答**：
- gptqmodel 主要用于 GPTQ 量化
- 对 AWQ 支持不如 vLLM 原生
- 安装复杂，依赖多
- vLLM 原生支持 AWQ，无需额外依赖

---

### Q2: autoawq 和 vLLM 选哪个？

**答**：

| 场景 | 推荐 |
|------|------|
| **生产环境/大量推理** | vLLM ✅ |
| **快速测试** | autoawq |
| **显存受限** | vLLM |
| **多卡并行** | vLLM |

**结论**：vLLM 综合最优，推荐使用。

---

### Q3: Python 3.11/3.12 可以用吗？

**答**：
- ⚠️ **不推荐**：vLLM 部分版本不支持
- ⚠️ 部分 C 扩展编译可能失败
- ✅ 建议使用 Python 3.10.x

---

### Q4: 为什么需要两张 A6000？

**答**：
- **72B AWQ 模型**：
  - 权重：~18GB（4-bit 量化）
  - KV cache：~10-20GB
  - 激活值：~5-10GB
  - 总需求：~40-50GB
  
- **单卡 49GB**：
  - 可能显存不足（长序列、大 batch）
  
- **双卡 98GB**：
  - ✅ 充足显存余量
  - ✅ 支持更长序列（max_length=2048）
  - ✅ 支持更大 batch size
