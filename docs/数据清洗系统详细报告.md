## 1. 概述

### 1.1 背景

在VLM（Vision-Language Model）知识蒸馏项目中，教师模型生成的蒸馏数据质量直接影响学生模型的训练效果。低质量数据（如低置信度答案、格式错误、幻觉推理等）会导致学生模型学到错误的模式，降低模型性能。

### 1.2 目标

数据清洗系统旨在：

- **提升数据质量**: 移除低质量、异常、错误的数据样本
- **保障数据可靠性**: 确保数据格式正确、内容合理
- **优化训练效果**: 为学生模型提供高质量的训练数据
- **提供可追溯性**: 记录清洗决策、生成详细报告

### 1.3 在蒸馏流程中的位置

```
教师模型 → 数据蒸馏 → 初始验证 → 【数据清洗】 → 最终验证 → 质量校验 → 学生模型训练
                                    ↑
                              当前模块
```

数据清洗在蒸馏生成数据后、训练学生模型前执行，是数据质量保障的关键环节。

### 1.4 核心价值

| 维度 | 价值 |
|------|------|
| **数据质量** | 移除低置信度、无效答案、格式错误等数据 |
| **训练效率** | 减少噪声数据，加速模型收敛 |
| **模型性能** | 高质量数据带来更好的学生模型表现 |
| **可维护性** | 详细报告支持问题追溯和参数优化 |

## 3. 核心功能详解

### 3.1 功能概览

| 功能 | 描述 | 方法 |
|------|------|------|
| 异常检测 | 多维度检测数据异常 | `_detect_anomalies()` |
| 质量评分 | 综合评估数据质量 | `_compute_quality_scores()` |
| 清洗规则 | 应用规则移除/保留数据 | `_apply_cleaning_rules()` |
| 数据去重 | 检测并标记重复数据 | `_deduplicate_data()` |
| 数据修复 | 自动修复可修复问题 | `_repair_data()` |
| 报告生成 | 生成详细清洗报告 | `_generate_cleaning_report()` |

### 3.2 异常检测维度

系统从**7个维度**检测数据异常：

#### 3.2.1 低置信度 (low_confidence)

**检测目标**: VQA答案置信度、检测目标置信度

**阈值**: `min_confidence` (默认0.5)

**示例**:
```python
# VQA答案置信度过低
{
    'image_id': '123456',
    'task': 'vqa',
    'confidence': 0.32,  # < 0.5
    'answer': 'blue',
    'type': 'low_confidence'
}
```

#### 3.2.2 无效答案 (invalid_answers)

**检测目标**: VQA答案内容是否有效

**无效答案列表**:
```python
['unknown', 'n/a', 'none', 'null', 'nothing',
 'i don\'t know', 'cannot determine', 'unclear',
 'no answer', 'not sure', 'indeterminate', '']
```

**示例**:
```python
# 无效答案
{
    'image_id': '123457',
    'task': 'vqa',
    'answer': 'unknown',
    'type': 'invalid_answer'
}
```

#### 3.2.3 空结果 (empty_results)

**检测目标**:
- VQA无答案
- Captioning无描述
- Detection无检测目标

**示例**:
```python
# 空检测结果
{
    'image_id': '123458',
    'task': 'detection',
    'type': 'no_objects'
}
```

#### 3.2.4 检测框异常 (bbox_anomalies)

**检测目标**: Detection任务的边界框异常

**异常类型**:
- `bbox_out_of_range`: 坐标超出合理范围
- `bbox_too_small`: 检测框过小 (< 5像素)
- `bbox_too_large`: 检测框过大 (> 900像素)
- `invalid_coordinates`: 坐标无效 (x_max ≤ x_min)

**示例**:
```python
# 异常检测框
{
    'image_id': '123459',
    'object': {'class': 'person', 'bbox': [1500, 2000, 1800, 2400]},
    'type': 'bbox_out_of_range',
    'bbox': [1500, 2000, 1800, 2400]  # 超出 [0, 1000] 范围
}
```

#### 3.2.5 CoT质量低 (cot_low_quality)

**检测目标**: 思维链推理质量

**质量指标**:
- `logical_flow_score`: 逻辑流畅度 (< 0.5 为低质量)
- `step_count`: 推理步骤数 (< 2 为不足)

**示例**:
```python
# 低质量CoT
{
    'image_id': '123460',
    'task': 'vqa',
    'quality_score': 0.32,  # < 0.5
    'type': 'low_cot_quality'
}
```

#### 3.2.6 长度异常 (length_anomalies)

**检测目标**: 答案、描述文本长度

**异常类型**:
- VQA答案过短 (< 3字符) 或过长 (> 100字符)
- Captioning描述过短 (< 15字符) 或过长 (> 200字符)

**示例**:
```python
# 答案过短
{
    'image_id': '123461',
    'task': 'vqa',
    'length': 2,
    'type': 'too_short',
    'threshold': 3
}
```

#### 3.2.7 格式错误 (format_errors)

**检测目标**: 数据格式是否符合规范

**示例**:
```python
# Bbox格式错误
{
    'image_id': '123462',
    'task': 'detection',
    'bbox': [100, 200],  # 应为4个值
    'type': 'invalid_bbox_format'
}
```

## 4. 清洗流程

### 4.1 完整流程图

```
┌─────────────────────────────────────────────────────────────┐
│                    数据清洗完整流程                              │
└─────────────────────────────────────────────────────────────┘

Step 1: 加载数据
    ├── 扫描输入目录所有JSON文件
    ├── 过滤checkpoint/summary文件
    └── 加载到内存

Step 2: 异常检测
    ├── 遍历每个数据样本
    ├── 检测VQA异常（置信度、答案有效性、长度、CoT质量）
    ├── 检测Captioning异常（空描述、长度）
    ├── 检测Detection异常（空结果、检测框异常）
    └── 汇总异常统计

Step 3: 质量评分
    ├── 计算每个样本综合质量分数（0-100分）
    ├── 硬标签质量评分（0-40分）
    ├── 软标签质量评分（0-20分）
    ├── CoT质量评分（0-30分）
    └── 任务特定加分（0-10分）

Step 4: 应用清洗规则
    ├── 规则1: 质量分数 < min_quality_score → 移除
    ├── 规则2: 无效答案 → 移除
    ├── 规则3: 空结果 → 移除（可配置）
    ├── 规则4: 格式错误 → 移除
    ├── 规则5: ≥2个任务低置信度 → 移除
    └── 规则6: CoT严重质量问题 → 移除

Step 5: 数据去重
    ├── 标准化答案文本（小写、去冠词、去标点）
    ├── 检测重复答案
    └── 标记但保留（供后续决策）

Step 6: 数据修复
    ├── 修复超出范围的检测框 → 裁剪到 [0, 1000]
    ├── 修复无效坐标 → 调整为有效值
    ├── 添加缺失的confidence字段
    └── 添加缺失的timestamp字段

Step 7: 生成清洗报告
    ├── 汇总统计数据
    ├── 计算质量分布
    ├── 生成改进建议
    └── 保存为JSON报告

Step 8: 保存结果
    ├── cleaned/ 目录：清洗后的数据
    ├── removed/ 目录：被移除的数据
    └── cleaning_report.json：详细报告
```

## 5. 质量评分体系

### 5.1 评分维度

每个数据样本的质量分数由以下部分组成：

| 维度 | 分值范围 | 说明 |
|------|---------|------|
| 硬标签质量 | 0-40分 | 答案置信度、完整性 |
| 软标签质量 | 0-20分 | 温度参数、分布完整性 |
| CoT质量 | 0-30分 | 逻辑流畅度、步骤数量 |
| 任务特定加分 | 0-10分 | 答案有效性、多样性等 |
| **总分** | **0-100分** | 综合质量分数 |

### 5.2 硬标签质量评分 (0-40分)

#### 置信度贡献 (最高30分)

```python
if confidence >= 0.7:
    score += 30  # 高置信度
elif confidence >= 0.5:
    score += 20  # 中等置信度
elif confidence >= 0.3:
    score += 10  # 低置信度
else:
    score += 0   # 极低置信度
```

#### 答案完整性 (最高10分)

```python
if min_answer_length <= len(answer) <= max_answer_length:
    score += 10  # 长度合理
else:
    score += 0   # 长度异常
```

### 5.3 软标签质量评分 (0-20分)

#### 温度参数合理性 (最高10分)

```python
if 1.5 <= temperature <= 3.0:  # 推荐范围
    score += 10
elif 1.0 <= temperature <= 5.0:  # 可接受范围
    score += 5
else:
    score += 0
```

#### 分布完整性 (最高10分)

```python
if distribution and len(distribution) > 0:
    score += 10
else:
    score += 0
```

### 5.4 CoT质量评分 (0-30分)

#### 逻辑流畅度 (最高15分)

```python
logical_flow = quality_metrics.get('logical_flow_score', 0.0)
score += logical_flow * 15  # 0.0-1.0 → 0-15分
```

#### 步骤数量合理性 (最高15分)

```python
step_count = quality_metrics.get('step_count', 0)

if 3 <= step_count <= 5:  # 最佳步骤数
    score += 15
elif 2 <= step_count <= 6:  # 可接受
    score += 10
elif step_count > 0:  # 有步骤但不理想
    score += step_count * 2
else:
    score += 0
```

### 5.5 任务特定加分 (0-10分)

#### VQA任务

```python
if answer and answer.lower() not in invalid_answers:
    score += 5  # 答案有效
```

#### Captioning任务

```python
if len(captions) >= 3:
    score += 5  # 多个caption
```

#### Detection任务

```python
if len(objects) >= 2:
    score += 5  # 检测到多个物体
```

### 5.6 质量分布

根据质量分数，数据被划分为三个等级：

| 等级 | 分数范围 | 占比目标 | 说明 |
|------|---------|---------|------|
| 高质量 | ≥ 70分 | > 60% | 可直接用于训练 |
| 中等质量 | 50-70分 | 20-40% | 可使用，需关注 |
| 低质量 | < 50分 | < 20% | 建议移除 |

## 6. 异常检测机制

### 6.1 VQA异常检测

```python
def _detect_vqa_anomalies(self, image_id, task_data, anomalies):
    """检测VQA任务的异常"""

    hard_label = task_data.get('hard_label', {})
    answer = hard_label.get('answer', '')
    confidence = hard_label.get('confidence', 0.0)

    # 1. 低置信度检测
    if confidence < self.min_confidence:
        anomalies['low_confidence'].append({...})

    # 2. 无效答案检测
    answer_lower = answer.lower().strip()
    if answer_lower in self.invalid_answers or not answer.strip():
        anomalies['invalid_answers'].append({...})

    # 3. 长度异常检测
    answer_len = len(answer.strip())
    if answer_len < self.min_answer_length:
        anomalies['length_anomalies'].append({...})
    elif answer_len > self.max_answer_length:
        anomalies['length_anomalies'].append({...})

    # 4. CoT质量检测
    cot = task_data.get('cot_reasoning', {})
    quality_metrics = cot.get('quality_metrics', {})

    if quality_metrics:
        logical_flow = quality_metrics.get('logical_flow_score', 0.0)
        if logical_flow < self.min_cot_quality:
            anomalies['cot_low_quality'].append({...})

        step_count = quality_metrics.get('step_count', 0)
        if step_count < 2:
            anomalies['cot_low_quality'].append({...})
```

### 6.2 Captioning异常检测

```python
def _detect_captioning_anomalies(self, image_id, task_data, anomalies):
    """检测Captioning任务的异常"""

    hard_label = task_data.get('hard_label', {})
    captions = hard_label.get('captions', [])

    # 1. 空caption检测
    if not captions or len(captions) == 0:
        anomalies['empty_results'].append({...})

    # 2. Caption质量检测
    valid_captions = [cap for cap in captions if len(cap.strip()) >= 10]
    if len(valid_captions) < len(captions):
        anomalies['empty_results'].append({...})

    # 3. Caption长度异常
    for i, caption in enumerate(captions):
        cap_len = len(caption.strip())
        if cap_len < 15:
            anomalies['length_anomalies'].append({...})
        elif cap_len > 200:
            anomalies['length_anomalies'].append({...})
```

### 6.3 Detection异常检测

```python
def _detect_detection_anomalies(self, image_id, task_data, anomalies):
    """检测Detection任务的异常"""

    hard_label = task_data.get('hard_label', {})
    objects = hard_label.get('objects', [])

    # 1. 无检测结果
    if not objects or len(objects) == 0:
        anomalies['empty_results'].append({...})

    # 2. 检测框异常
    for obj in objects:
        bbox = obj.get('bbox', [])
        confidence = obj.get('confidence', 0.0)

        # 格式错误
        if len(bbox) != 4:
            anomalies['format_errors'].append({...})
            continue

        x_min, y_min, x_max, y_max = bbox

        # 超出范围检测
        if x_min < 0 or y_min < 0 or x_max > 1000 or y_max > 1000:
            anomalies['bbox_anomalies'].append({...})

        # 尺寸异常
        width = x_max - x_min
        height = y_max - y_min

        if width < 5 or height < 5:
            anomalies['bbox_anomalies'].append({...})

        if width > 900 or height > 900:
            anomalies['bbox_anomalies'].append({...})

        # 坐标异常
        if x_max <= x_min or y_max <= y_min:
            anomalies['bbox_anomalies'].append({...})

        # 低置信度检测
        if confidence < self.min_confidence:
            anomalies['low_confidence'].append({...})
```

## 7. 使用方法

### 7.1 方式一: 命令行脚本（推荐）

#### 基本用法

```bash
# 使用默认参数清洗数据
python scripts/clean_data.py --input ./outputs/merged

# 输出
Input directory: ./outputs/merged
Found 1000 data files to clean

[Step 1] Loading data...
Loaded 1000 data files

[Step 2] Detecting anomalies...
Anomalies detected: {'low_confidence': 45, ...}

[Step 3] Computing quality scores...
Average quality score: 67.5

[Step 4] Applying cleaning rules...
Cleaned: 850, Removed: 150

...

✓ Data cleaning completed successfully!
```

#### 自定义参数

```bash
# 自定义阈值
python scripts/clean_data.py \
    --input ./outputs/merged \
    --min-confidence 0.6 \
    --min-quality 40

# 保留无效数据（仅标记）
python scripts/clean_data.py \
    --input ./outputs/merged \
    --keep-invalid

# 禁用自动修复
python scripts/clean_data.py \
    --input ./outputs/merged \
    --no-repair

# 禁用去重
python scripts/clean_data.py \
    --input ./outputs/merged \
    --no-deduplicate

# 指定输出目录
python scripts/clean_data.py \
    --input ./outputs/merged \
    --output ./outputs/final

# 详细日志
python scripts/clean_data.py \
    --input ./outputs/merged \
    --verbose

# 测试模式（不保存文件）
python scripts/clean_data.py \
    --input ./outputs/merged \
    --dry-run
```

### 9.2 关键指标解读

#### 移除率 (removal_rate)

- **< 10%**: 清洗较温和，保留大部分数据
- **10-20%**: 正常范围，数据质量良好

- **> 30%**: 数据质量严重问题，建议检查蒸馏流程

#### 平均质量分数 (average_quality_score)

- **≥ 80**: 优秀，数据质量很高
- **70-80**: 良好，适合训练
- **60-70**: 中等，可使用但需关注低质量样本
- **< 60**: 较差，建议调整清洗参数或重新生成数据

#### 质量分布 (quality_distribution)

- **高质量占比 > 60%**: 数据质量优秀
- **中等质量占比 20-40%**: 正常范围
- **低质量占比 > 20%**: 数据质量问题

### 12.2 质量评分完整逻辑

```python
def _compute_task_quality(self, task_name: str, task_data: Dict) -> float:
    """计算任务质量分数（完整版本）"""
    score = 0.0

    # 1. 硬标签质量 (0-40分)
    hard_label = task_data.get('hard_label', {})
    if hard_label:
        confidence = hard_label.get('confidence', 0.0)

        # 置信度贡献 (最高30分)
        if confidence >= 0.7:
            score += 30
        elif confidence >= 0.5:
            score += 20
        elif confidence >= 0.3:
            score += 10

        # 答案完整性 (最高10分)
        answer = hard_label.get('answer', '')
        if self.min_answer_length <= len(answer) <= self.max_answer_length:
            score += 10

    # 2. 软标签质量 (0-20分)
    soft_label = task_data.get('soft_label', {})
    if soft_label:
        temperature = soft_label.get('temperature', 0.0)
        if 1.5 <= temperature <= 3.0:
            score += 10
        elif 1.0 <= temperature <= 5.0:
            score += 5

        distribution = soft_label.get('answer_distribution', {})
        if distribution and len(distribution) > 0:
            score += 10

    # 3. CoT质量 (0-30分)
    cot = task_data.get('cot_reasoning', {})
    if cot:
        quality_metrics = cot.get('quality_metrics', {})

        logical_flow = quality_metrics.get('logical_flow_score', 0.0)
        score += logical_flow * 15

        step_count = quality_metrics.get('step_count', 0)
        if 3 <= step_count <= 5:
            score += 15
        elif 2 <= step_count <= 6:
            score += 10
        elif step_count > 0:
            score += step_count * 2

        reasoning_length = len(cot.get('raw_reasoning', ''))
        if 50 <= reasoning_length <= 300:
            score += 5

    # 4. 任务特定加分 (0-10分)
    if task_name == 'vqa':
        answer = hard_label.get('answer', '')
        if answer and answer.lower() not in self.invalid_answers:
            score += 5

    elif task_name == 'captioning':
        captions = hard_label.get('captions', [])
        if len(captions) >= 3:
            score += 5

    elif task_name == 'detection':
        objects = hard_label.get('objects', [])
        if len(objects) >= 2:
            score += 5

    return min(score, 100.0)
```
