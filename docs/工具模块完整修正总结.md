# 工具模块完整修正总结

## 📋 核心理解

候选集封闭系统的正确流程：

```
数据准备 → 词表生成 → 候选集封闭 → 软标签生成
   ↓           ↓           ↓           ↓
COCO数据 → vqa_vocab.json → 动态候选集 → 分布计算
```

## ✅ 已完成的修正

### 1. 删除不必要的文件

- ❌ `tools/candidate/closure.py` - 简化版（已删除）
- ❌ 所有测试文件（已删除）

### 2. 候选集封闭系统修正

**文件**: `tools/candidate/candidate_closure.py`

**核心流程**:
1. **问题类型分类** - 使用零样本分类模型（bart-large-mnli）
2. **候选集生成** - 根据分类结果选择预定义答案集
3. **保底策略** - 确保primary_answer在候选集中

**使用方式**:
```python
from tools.candidate.candidate_closure import CandidateClosure

# 初始化
closure = CandidateClosure(config)

# 获取候选集
candidates = closure.get_candidates_for_question(question, primary_answer)
```

### 3. VQA词表生成脚本修正

**文件**: `tools/candidate/generate_vqa_vocab.py`

**修改内容**:
- ✅ 支持从多个数据源统计生成
- ✅ merged数据（推荐）- 从已蒸馏数据提取答案
- ✅ vqa数据 - 从VQA v2标注文件提取
- ✅ coco数据 - 从COCO Captions提取词汇

**使用方式**:
```bash
# 推荐：从merged数据生成
python tools/candidate/generate_vqa_vocab.py --source merged

# 其他方式
python tools/candidate/generate_vqa_vocab.py --source vqa
python tools/candidate/generate_vqa_vocab.py --source all
```

### 4. 统一入口修正

## 🎯 核心优势

### 1. 动态候选集生成

```python
# 传统方式：固定候选集
candidates = ["one", "two", "three", ...]  # 对所有问题都一样

# 新方式：问题感知候选集
question = "How many people?"
candidates = closure.get_candidates_for_question(question, primary_answer)
# 结果：["three", "zero", "one", "two", "four", ...]  # 针对计数问题
```

### 2. 保底策略

```python
# 确保主答案在候选集中
question = "What instrument is this?"
primary_answer = "xylophone"  # 罕见答案

candidates = closure.get_candidates_for_question(question, primary_answer)
# 结果：["xylophone", "guitar", "piano", ...]  # xylophone被强制添加
```

### 3. 自动集成

```python
# 软标签生成器自动调用候选集封闭
generator = VQASoftLabelGenerator(config)
soft_label = generator.generate(image, question)

# 内部自动完成：
# 1. 问题分类
# 2. 候选集生成
# 3. 分布计算
```
