## 1. 环境准备

### 1.1 系统要求

```yaml
最低配置:
  - 操作系统: Linux (Ubuntu 20.04+) / Windows 10+ / macOS
  - Python: 3.8 - 3.11
  - GPU: NVIDIA GPU, CUDA 11.8+
  - 内存: 至少32GB RAM
  - 存储: 至少50GB可用空间

推荐配置:
  - GPU: NVIDIA A100/V100 (32GB+ VRAM)
  - 内存: 64GB+ RAM
  - 存储: SSD, 100GB+
```

### 1.2 安装步骤

```bash
# Step 1: 克隆项目
git clone https://github.com/yourusername/vlm-distillation.git
cd vlm-distillation

# Step 2: 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/macOS
# 或: venv\Scripts\activate  # Windows

# Step 3: 安装依赖
pip install -r requirements.txt

# Step 4: 安装项目包
pip install -e .

# Step 5: 验证安装
python -c "from src import ConfigManager; print('OK')"
```

## 3. 配置说明

### 3.1 主配置文件 (configs/default.yaml)

```yaml
# 教师模型配置
teacher:
  model_name: "Qwen/Qwen2.5-VL-7B-Instruct"
  device: "cuda"
  precision: "bf16"  # bfloat16精度

# 数据配置
data:
  coco_root: "./data/coco"
  max_samples: 100   # 测试时用少量样本
  batch_size: 4

# 蒸馏配置
distillation:
  tasks: ["vqa", "captioning", "detection"]
  
  hard_labels:
    enabled: true
    confidence_threshold: 0.7
  
  soft_labels:
    enabled: true
    temperature: 2.0
    top_k_logits: 100
  
  cot:
    enabled: true
    max_length: 512

# 清洗配置
cleaning:
  min_quality_score: 50.0
  min_confidence: 0.6

# ✨ 可视化配置 (更新)
visualization:
  output_dir: "./outputs/visualizations"
  plot_format: "png"
  dpi: 150

# 输出配置
output:
  root_dir: "./outputs"
```

### 3.2 配置修改方式

```python
from src import ConfigManager

config = ConfigManager()

# 方式1: 直接修改YAML文件

# 方式2: 代码中动态修改
config.set('data.max_samples', 100)
config.set('distillation.tasks', ['vqa'])

# 方式3: 命令行参数覆盖
# python scripts/run_full_pipeline.py --samples 100 --tasks vqa
```

## 5. 常用操作

### 5.1 分步骤运行

```bash
# Step 1: 仅蒸馏
python scripts/run_distillation.py --samples 100

# Step 2: 仅清洗
python scripts/clean_data.py --input outputs/merged --min-quality 40

# Step 3: 仅可视化 (需要指定输入目录)
python scripts/run_full_pipeline.py --steps visualization --enable-visualization \
    --input-dir outputs/cleaned/cleaned \
    --before-dir outputs/merged
```

### 5.2 Python API调用

```python
from scripts.run_full_pipeline import FullPipelineRunner

# 初始化
runner = FullPipelineRunner('configs/default.yaml')

# 运行完整流程
result = runner.run_full_pipeline(
    max_samples=100,
    tasks=['vqa', 'captioning'],
    min_quality=40.0,
    min_confidence=0.6
)

# 查看结果
print(f"成功: {result['success']}")
print(f"步骤: {result['steps_completed']}")

# 查看耗时统计
timing = result['timing_stats']
print(f"蒸馏耗时: {timing['distillation']['duration']}s")
print(f"清洗耗时: {timing['cleaning']['duration']}s")
```

### 5.3 断点续传

```bash
# 如果中途停止，可继续
python scripts/run_distillation.py --samples 5000 --resume outputs/checkpoint_latest.json
```

## 6. 可视化功能

### 6.1 四个核心图表

| 图表 | 文件名 | 说明 |
|------|--------|------|
| **分数对比** | `score_comparison.png` | 质量分数和置信度的对比折线图 (上下两个子图) |
| **样本数量** | `sample_count.png` | Before/After/Removed 样本数量的柱状图 |
| **样本可视化** | `sample_*.png` | 最多10张样本的图像+标签+CoT展示 |
| **耗时折线** | `pipeline_timing.png` | 各步骤耗时和累计时间的折线图 |

### 6.2 生成可视化

```bash
# 方式1: 在完整流程中启用
python scripts/run_full_pipeline.py --samples 100 --enable-visualization

# 方式2: 单独运行可视化
python scripts/run_full_pipeline.py --steps visualization --enable-visualization \
    --input-dir outputs/cleaned/cleaned \
    --before-dir outputs/merged
```

### 6.3 可视化结果解读

**score_comparison.png**:
- 上子图: 质量分数对比 (清洗前后)
- 下子图: 置信度对比 (清洗前后)
- 红线: 清洗前数据
- 绿线: 清洗后数据
- 橙色虚线: 阈值线

**sample_count.png**:
- Before: 清洗前样本数
- After: 清洗后样本数
- Removed: 移除样本数
- 显示保留率

**sample_*.png**:
- 左侧: 原始图像
- 右上: 标签信息 (答案+置信度)
- 右下: CoT推理过程

**pipeline_timing.png**:
- 上子图: 各步骤耗时折线图 (标注具体秒数)
- 下子图: 累计耗时曲线 + 单步耗时柱状图
